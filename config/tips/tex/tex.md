## ルート・バーのずれ補正

文字の高さ（ascender / descender の有無）によって、根号や上線の高さ・形が変わってしまうことがある。
下表のコマンドで見えない支柱（phantom）を入れると高さが揃う。

### 補正用コマンド

| コマンド | 働き | 主な用途 |
| --- | --- | --- |
| `\vphantom{X}` | 幅 0・高さ／深さは `X` と同じ見えない箱 | 根号・上線の高さを揃える |
| `\hphantom{X}` | 高さ 0・幅は `X` と同じ見えない箱 | 横幅を揃える |
| `\phantom{X}` | 幅・高さ・深さが `X` と同じ見えない箱 | 位置合わせ全般 |
| `\mathstrut` | `\vphantom{(}` と同じ | 根号・上線の高さを標準に揃える |
| `\smash{X}` | `X` の高さ・深さを 0 として扱う | 根号が大きくなりすぎるのを防ぐ |
| `\smash[t]{X}` | 上側の高さだけ 0 にする | 上に突き出る文字の影響を消す |
| `\smash[b]{X}` | 下側の深さだけ 0 にする | `y` `g` `p` などの下端の影響を消す |
| `\rule{0pt}{h}` | 幅 0・高さ `h` の見えない棒 | 高さを数値で直接指定する |
| `\displaystyle` | 分数・和などを大きい表示にする | 根号内の分数が小さくなるのを防ぐ |

### 症状別の補正例
