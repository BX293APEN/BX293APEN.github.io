分類






名称略号記号・図説明特徴
単極スイッチ(●)
 —
  • 1か所から照明などを点滅させる基本のスイッチ
  • 電源の非接地側(黒線)に入れる
  • 3路・4路スイッチと組み合わせて使う
3路スイッチ(●3)
 —
  • 2か所から同じ照明を点滅させる
  • 2個1組で使う
  • スイッチ間は3線で結ぶ
  • 端子は0・1・3の3つ
4路スイッチ(●4)
 —
  • 3か所以上から同じ照明を点滅させる
  • 2個の3路スイッチの間に入れる
  • 端子は4つ
プルスイッチ(●P)
 —
  • ひもを引いて入切するスイッチ
  • 天井から吊るした照明などに使う
確認表示灯内蔵スイッチ(●L)
 —
  • 負荷が動作中であることを知らせるランプ内蔵
  • 換気扇や屋外灯などの動作確認に便利
  • 負荷と並列に接続する
位置表示灯内蔵スイッチ(●H)
 —
  • スイッチの位置を暗所で知らせるランプ内蔵
  • 照明が消えているときにランプが点灯する
自動点滅器(●A)
 —
  • 明るさを検知して自動で点滅する
  • 屋外灯などに使う
  • 図記号の横に容量(例: 3A)を併記する
コンセント(壁付)
 —
  • プラグを差し込んで電源を取り出す
  • 一般は125V 15A
  • 接地側極(長い方の刃受け)は向かって左側
  • ここに白線(接地側電線)をつなぐ
  • 円の下側を塗りつぶして壁付を表す
天井取付コンセント
 —
  • 天井に取り付けるコンセント
  • 塗りつぶしなしで表す
2口コンセント(2)
 —
  • 差込口が2つのコンセント
  • 図記号の横の数字が口数を表す
3口コンセント(3)
 —
  • 差込口が3つのコンセント
  • 図記号の横の数字が口数を表す
接地極付コンセント(E)
 —
  • 接地極を備えたコンセント
  • 洗濯機・エアコンなど水気のある場所や大型機器向け
接地端子付コンセント(ET)
 —
  • 接地端子を備えたコンセント
  • 接地線を端子にねじ止めして使う
接地極・接地端子付コンセント(EET)
 —
  • 接地極と接地端子の両方を備えたコンセント
  • 接地極付と接地端子付を兼ねる
漏電遮断器付コンセント(EL)
 —
  • 漏電遮断器を内蔵したコンセント
  • 水回りなど漏電のおそれがある場所向け
抜け止め形コンセント(LK)
 —
  • プラグを差し込んで回すと抜けにくくなる
  • 振動や引っ張りでプラグが外れるのを防ぐ
防雨形コンセント(WP)
 —
  • 雨水などがかかる場所用
  • 屋外・水回りで使う
引掛形コンセント(T)
 —
  • ひねって固定する形のコンセント
  • 抜け止め形の一種
  • 専用プラグを使う
白熱灯
 —
  • 白熱電球を使う照明器具
  • 図記号は単純な円
壁付白熱灯
 —
  • 壁に取り付ける白熱灯
  • 円の下側を塗りつぶす
蛍光灯
 —
  • 蛍光ランプを使う照明器具
  • 円の左右に長方形を付けて表す
シーリング(CL)
 —
  • 天井に直接取り付ける照明器具
  • 円の中にCLを書く
配線用遮断器(B)
 —
  • 過負荷や短絡の過電流で自動的に回路を遮断する

配線用遮断器の動作特性

項目値
定格電流30A以下定格電流の1倍で動作しない
同上1.25倍で60分以内に動作
同上2倍で2分以内に動作
  • 通称ノーヒューズブレーカ
  • 遮断後は手動で復帰できる
漏電遮断器(E)
 —
  • 漏電(地絡)を検知して回路を遮断する
  • 高感度・高速形は定格感度電流30mA以下
  • 動作時間は0.1秒以内
  • テストボタン付き
開閉器(S)
 —
  • 回路を開閉するスイッチ
  • 引込口付近などで使う
電力量計(Wh)
 —
  • 使用した電力量を積算して測る
  • 電力会社が取り付ける計器
電動機(M)
 —
  • モータ
  • 三相誘導電動機などを表す
分電盤
 —
  • 各回路へ電気を分ける盤
  • 長方形を対角線で分け、片側を塗りつぶして表す
  • 主開閉器・分岐ブレーカ・漏電遮断器などを収める
接地(アース)
 —
  • 感電や機器破損を防ぐため機器の金属部を大地に接続する
  • D種接地工事は接地抵抗100Ω以下
  • 0.5秒以内に動作する漏電遮断器を設ければ500Ω以下でよい
押しボタン
 —
  • ベル・ブザーなどを鳴らすための押しボタンスイッチ
  • 四角の中に黒丸で表す
リモコンスイッチ(●R)
 —
  • リモコンリレーを操作する低電圧用スイッチ
  • リモコントランス(小形変圧器)から約24Vを供給する
  • 1つのリレーを複数か所から操作できる
リモコンリレー(▲)
 —
  • リモコンスイッチの信号で照明などの回路を開閉する
  • 三角形(塗りつぶし)で表す
  • リモコン配線は二次側(低圧)の細い電線を使う
リモコントランス
 —
  • リモコンリレーとセットで使う
 —
小形変圧器
 —
  • 一次側は100V、二次側は低電圧
 —
ベル
 —
  • 押しボタンの操作で鳴る呼出し装置
  • 小形変圧器・押しボタンとセットで使う
ブザー
 —
  • 押しボタンの操作で鳴る呼出し装置
  • ベルより低い音
チャイム
 —
  • 押しボタンの操作で鳴る呼出し装置
  • 玄関の呼出しなどに使う
引掛シーリング(角形)

  • 角形は長方形の中にかっこを書く
引掛シーリング(丸形)
 —
  • 天井に取り付け、照明器具を引っ掛けて接続する器具
  • 丸形は円の中にかっこを書く
ダウンライト(DL)
 —
  • 天井に埋め込む照明器具
  • 円の中にDLを書く
天井付換気扇
 —
  • 室内の空気を入れ替える電動ファン
  • 天井に取り付ける
壁付換気扇
 —
  • 室内の空気を入れ替える電動ファン
  • 壁に取り付ける
  • 確認表示灯内蔵スイッチ(●L)と組み合わせることが多い
点検口
 — —
  • 天井裏や床下を点検するための出入口
  • 配線図では点検口の位置を示す
電磁開閉器(MC)
 — —
  • 電動機の始動・停止に使う電磁接触器に熱動継電器を組み合わせたもの
  • 押しボタンスイッチで操作する
  • 電動機の過負荷を保護する
電磁接触器
 — —
  • 電磁石の力で主回路を開閉する
  • 過負荷保護機能はない
  • 熱動継電器と組み合わせて電磁開閉器になる
熱動継電器(サーマルリレー)
 — —
  • 電動機の過負荷電流を検出して動作する保護継電器
  • 短絡電流は遮断できない
  • 電磁接触器と組み合わせて使う
進相コンデンサ
 —
  • 力率を改善するためのコンデンサ
  • 負荷(電動機など)と並列に接続する
  • 無効電力を減らし、電流・電力損失を小さくする
ヒューズ(低圧)
 — —
  • 過電流で溶断して回路を保護する
  • 定格電流30A以下: 1.6倍で60分以内、2倍で2分以内に溶断
  • 溶断後は交換が必要

  • 対地電圧150V超300V以下は0.2MΩ以上
接地抵抗計(アーステスタ)
 — —
  • 接地抵抗を測る
  • 補助接地極を2本打つ
  • 被測定接地極から直線上に約10mずつ離す
回路計(テスタ)
 — —
  • 電圧・抵抗・導通などを測る
  • 交流・直流の電圧が測れる
  • 抵抗測定時は回路に電圧をかけない

オームの法則
 — $V = IR$
  • V: 電圧[V]
  • I: 電流[A]
  • R: 抵抗[Ω]
 —
直列接続の合成抵抗
 — $R = R_1 + R_2$
  • 電流は共通
  • 電圧は抵抗に比例して分かれる
 —
並列接続の合成抵抗
 — $R = \dfrac{R_1 R_2}{R_1 + R_2}$
$\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2}$
  • 電圧は共通
 —
分圧
 — $V_1 = \dfrac{R_1}{R_1 + R_2}V$
  • 直列回路で使う
 —
分流
 — $I_1 = \dfrac{R_2}{R_1 + R_2}I$
  • 並列回路で使う
 —
電力
 — $P = VI = I^2 R = \dfrac{V^2}{R}$
  • P: 電力[W]
 —
電力量
 — $W = Pt$
  • 単位はW・hやkW・h
  • 1 kW・h = 3600 kJ
 —
ジュール熱
 — $Q = I^2 R t$
  • Q: 熱量[J]
  • t: 時間[s]
 —
電線の抵抗
 — $R = \rho \dfrac{L}{A}$
  • ρ: 抵抗率
  • L: 長さ
  • A: 断面積
 —
単相2線式の電圧降下
 — $v = 2Ir$
$V_s = V_r + 2Ir$
  • r: 電線1線の抵抗
  • 行きと帰りの2線分を考える
 —
三相3線式の電圧降下
 — $v = \sqrt{3}\, Ir$
  • r: 電線1線の抵抗
 —
誘導リアクタンス
 — $X_L = 2\pi f L$
  • f: 周波数[Hz]
  • L: インダクタンス[H]
 —
容量リアクタンス
 — $X_C = \dfrac{1}{2\pi f C}$
  • C: 静電容量[F]
 —
RL直列のインピーダンス
 — $Z = \sqrt{R^2 + X_L^2}$
$I = \dfrac{V}{Z}$
  • Z: インピーダンス[Ω]
 —
RC直列のインピーダンス
 — $Z = \sqrt{R^2 + X_C^2}$ —
力率
 — $\cos\theta = \dfrac{P}{VI} = \dfrac{R}{Z}$
  • P: 有効電力[W]
  • VI: 皮相電力[V・A]
 —
単相交流の電力
 — $P = VI\cos\theta$ —
三相交流の電力
 — $P = \sqrt{3}\, VI\cos\theta$
  • V: 線間電圧
  • I: 線電流
 —
変圧器
 — $\dfrac{V_1}{V_2} = \dfrac{N_1}{N_2} = \dfrac{I_2}{I_1}$
  • N: 巻数
  • 1が一次側
  • 2が二次側
 —
同期速度
 — $N_s = \dfrac{120 f}{p}$
  • Ns: 同期速度[min⁻¹]
  • p: 極数
 —
すべりと回転速度
 — $s = \dfrac{N_s - N}{N_s}$
$N = N_s (1 - s)$
  • s: すべり
  • N: 回転速度[min⁻¹]
 —
合成静電容量(並列)
 — — $C = C_1 + C_2$ —
合成静電容量(直列)
 — — $C = \dfrac{C_1 C_2}{C_1 + C_2}$ —
正弦波交流の実効値
 — — $V = \dfrac{V_m}{\sqrt{2}}$
  • Vm: 最大値

 — — $T = \dfrac{1}{f}$
  • T: 周期[s]
  • f: 周波数[Hz]

単相3線式の電圧降下
 — — $v = Ir$
  • 中性線に電流が流れない平衡時は、電圧降下は1線分

Y結線(星形)
 — — $V_l = \sqrt{3}\,V_p$
$I_l = I_p$
  • l: 線間・線電流
  • p: 相電圧・相電流
 —
Δ結線(三角形)
 — — $V_l = V_p$
$I_l = \sqrt{3}\,I_p$		 —

三相の消費電力(抵抗負荷)
 — — $P = 3I^2 R$
  • I: 線電流、R: 1相の抵抗
 —
水の加熱
 — — $Pt \cdot \eta = mc\Delta T$
  • m: 水の質量[kg]
  • c: 比熱(水は約4.2kJ/(kg・K))
  • η: 効率

無効電力・皮相電力
 — — $S = VI$
$Q = VI\sin\theta$
$S^2 = P^2 + Q^2$
  • S: 皮相電力[V・A]
  • Q: 無効電力[var]

電圧降下率
 — — $\dfrac{V_s - V_r}{V_r} \times 100\ [\%]$
  • Vs: 送電端電圧
  • Vr: 受電端電圧

許容電流と電流減少係数
 — — $I_a = I_0 \times k$
  • I0: 基本の許容電流
