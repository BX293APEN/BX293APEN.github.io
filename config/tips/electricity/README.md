# 電気工事士まとめ HTML/CSS/JS 変換

`md/electricity.md`(1つの Markdown の表)を、タグ検索付きの Bootstrap 用 HTML・CSS・JS に変換する。
`auth`(認証技術まとめ)の仕組みを、そのまま電気工事士のまとめ表に使えるようにしたもの。

## 使い方

Python 3.8 以上があればよい(追加のライブラリは不要)。

| コマンド | 内容 |
|---|---|
| `python build.py` | `md/*.md` をすべて変換し、`out/` に書き出す |
| `python build.py --preview` | 上に加えて、確認用ページ(`out/electricity-preview.html`)も書き出す |
| `python build.py electricity` | 指定した Markdown(`md/electricity.md`)だけ変換する |

確認用ページは、ブラウザで開くだけで動く(Bootstrap と KaTeX は CDN から読むため、ネットワークが必要)。

## フォルダ構成

| パス | 内容 |
|---|---|
| `build.py` | 変換スクリプト |
| `md/electricity.md` | **元データ**。編集するのはここ |
| `template/template.html` | HTML のひな形(`__FILTERS__` `__HEAD__` `__ROWS__` `__EXTRA__` と ID を置き換える) |
| `template/template.css` | CSS のひな形。**ID(`__APP_ID__`)だけ**を置き換える |
| `template/template.js` | JS のひな形。**引数(4つの ID)だけ**を置き換える |
| `preview/table-search.js` | 確認用の `createTableSearch` 簡易版(本番では使わない) |
| `out/` | 出力先(生成済み) |

## 出力ファイルと ID

| 出力 | ファイル名 | 元 | 置き換えるもの |
|---|---|---|---|
| HTML 断片 | `out/electricity.html` | `template.html` | 表の中身と ID |
| CSS | `out/electricity-style.css` | `template.css` | `#__APP_ID__` → `#electricity-app` |
| JS | `out/electricity-script.js` | `template.js` | `appId` `inputId` `countId` `clearId` |

| 引数 | 値 |
|---|---|
| `appId` | `electricity-app` |
| `inputId` | `electricity-q` |
| `countId` | `electricity-count` |
| `clearId` | `electricity-clear` |

ID は Markdown のファイル名で決まる。`md/` に別の Markdown を足せば、別の ID で別の表として出力できる。

## 補助表のネスト先

補助表は、説明欄のセルに `<table>` として書く(検索の対象にもなる)。

| 補助表 | ネスト先(説明欄) |
|---|---|
| 配線用遮断器の動作特性 | 行「配線用遮断器(B)」 |
| リングスリーブによる圧着接続の目安 | 行「リングスリーブ」 |
| 電線の太さと許容電流 / 電流減少係数 | 行「600Vビニル絶縁電線」 |
| 計器の記号と配置(2表) | 記録「計器の記号と配置」 |
| 竣工検査の流れ | 記録「竣工検査の流れ」 |
| 配線工事ごとの主な規定 | 記録「配線工事ごとの主な規定(数値)」 |
| 接地工事の表 | 記録「接地工事の種類」 |
| 分岐回路の表 / 電圧区分の表 | 記録「分岐回路の保護装置と電線の太さ」/「電圧区分」 |
| 電気工事士法・施工範囲の表 | 記録「電気工事士法・施工範囲」 |
| 電線管付属品・ボックス類 | ネストせず、12行の通常の行(分類 `付属品・ボックス`) |
| 電線管のサイズ(呼び径・呼び径の基準) | ネストせず、各電線管の行に統合(下の表) |
| 外径の表(薄鋼C・ねじなしE)と注記 | 行「薄鋼電線管」の説明欄 |

セル内の表は、`build.py` が自動で整える(Bootstrap の表にする・見出しの固定を外す・幅を `NEST_WIDTH` に固定して折り返す・短いセルは折り返さない)。

## 電線管の呼び径(各行に統合)

| 列 | 書き方 | 例(厚鋼電線管) |
|---|---|---|
| 説明 | 既存の `<ul>…</ul>` の後ろに、`<br><b>呼び径</b><br>値` | `…</ul><br><b>呼び径</b><br>16, 22, 28, …` |
| 特徴 | 同じく、`<br><b>呼び径の基準</b><br>偶数/奇数: …` | `…</ul><br><b>呼び径の基準</b><br>偶数: 内径に近い値` |

空行の入れ方 : `</ul>` の直後は `<br>` 1つで1行空く。テキストの直後(数字など)は `<br><br>` で1行空く(`<br>` 1つだと改行だけで空かない)。

## Markdown の書式(`md/electricity.md`)

| 要素 | 書き方 | 変換後 |
|---|---|---|
| `## 見出し` | 先頭に1つ | 確認用ページの見出しにだけ使う(断片には出さない) |
| 最初の表 | 先頭列は名前 | メイン表(検索・タグ絞り込み・見出しと先頭列の固定) |
| `分類` 列 | メイン表の列。見出しが `分類` | 表示せず、タグにする。なければタグなし |
| セル内の `<table>` | 説明欄などに1行で書く | 整えて、そのまま出す |
| インライン SVG | セルに `<svg …>` を直接書く(`currentColor`) | そのまま |
| 公式 | `$...$`(TeX) | そのまま(描画は貼り付け先) |
| 空欄・`-` | | 灰色の `—` |

### 分類列の決まり

| 決まり | 内容 |
|---|---|
| 経路 | `大分類 > 分類`。1段だけでも可 |
| 複数の分類 | `<br>` で区切る(例 : `配線器具・図記号 > 遮断器・開閉器<br>配線器具・図記号 > 電動機・動力`) |
| タグ | 経路の全要素がタグ。大分類を選ぶと、その下の分類の行もすべて残る。同じ名前を別の大分類の下に重ねるとエラー |

## 行を足すとき

| 作業 | 手順 |
|---|---|
| 行を足す | 表に1行足す。列数は見出しと同じ(6列)にする。合わないと行番号つきのエラー |
| 分類を足す | `分類` 列に新しい名前を書く。ボタンは自動で増える |
| 列の幅を変える | `build.py` の `NARROW_COLS`(狭くする列の見出し)/ `NARROW_STYLE` / `NEST_WIDTH`(セル内の表の幅) |

## 元の `electricity.md` からの変更点

| 変更 | 理由 |
|---|---|
| 列を「名称 / 分類 / 略号 / 記号・図 / 説明 / 特徴」にそろえた | 分野ごとに違った列を、1つの表にするため |
| `分類` 列を追加 | タグ絞り込みのため(`auth.md` と同じ方式)。分類名は自由に直してよい |
| 計算式は「公式」を説明欄、「回路図例」を記号・図の列に入れた | 列をそろえるため |
| 補助表をネスト・記録化(上の表) | 表の数を減らすため |
| 「リモコントランス」「小形変圧器」の行に空セルを追加 | 「特徴」列が欠けていた |
| 冒頭の注記(SVG・TeX・空欄の説明)を削除 | 書式の説明なので、この README の表に移した |
