フィールド名種別説明属性説明値説明
 
Content-Type
共通ボディのメディアタイプ--
[type]/[subtype]
メディアタイプ (type/subtype形式)
--
text/html
HTML文書
--
application/xml
XML文書
--
application/x-www-form-urlencoded
XHR/Fetch: フォーム形式の送信
--
application/json
XHR/Fetch: JSONの送受信 (クロスオリジンではプリフライト対象)
--
multipart/form-data
XHR/Fetch: ファイル送信 (FormData 使用時はブラウザが自動付与)
charset
文字エンコーディング (テキスト系で指定)
UTF-8
Unicode (UTF-8)
boundary
multipartの区切り文字列 (multipart/form-data 時に必須)
[文字列]
区切りに使う任意の文字列
 
Content-Length
共通ボディのサイズ (Transfer-Encoding 使用時は付与しない)--
[バイト数]
ボディのバイト数
Content-Encoding
共通ボディに適用された圧縮形式 (Accept-Encoding の中から選択される)--
gzip
gzip圧縮
--
deflate
deflate圧縮
--
br
Brotli圧縮
Transfer-Encoding
共通ボディの転送方式 (HTTP/2以降は不使用)--
chunked
サイズ不明のデータを分割送信
Connection
共通ネットワーク接続状態の制御 (HTTP/2以降は不使用)--
keep-alive
接続の維持
--
close
接続の切断
--
Upgrade
プロトコル切替
Date
共通メッセージ生成日時--
[ddd, dd MMM yyyy HH:mm:ss GMT]
生成日時 (常にGMT)
 
Cache-Control
共通キャッシュの扱い方
(コンマ区切りで複数指定)
no-cache
使用前に毎回サーバへ検証--
no-store
キャッシュ禁止 (保存しない)--
public
共有キャッシュ可--
private
ブラウザのみ可--
max-age
有効期間
[秒数]
有効期間の秒数 (例: max-age=3600)
s-maxage
共有キャッシュ向けの有効期間
[秒数]
共有キャッシュ向け有効期間の秒数
must-revalidate
期限切れなら必ず確認--
immutable
有効期間中は更新されない (再検証不要)--
no-transform
中継が内容を変換することを禁止--
 
Authorization
リクエスト認証情報をサーバへ提示する
Basic
Basic認証
[BASE64(user:pass)]
ユーザ名:パスワードをBASE64変換した値
Bearer
トークン認証 (OAuth 2.0 / JWT 等)
[アクセストークン]
発行されたトークン文字列
 
Host
リクエスト
  • 接続先サーバ (HTTP/1.1では必須)
  • ドメインフロンティング対策
    TLSのSNI(接続先サーバ名)とHostヘッダの不一致を検知・拒否する実装がある
--
[host]:[port]
ホスト名 + ポート番号 (既定ポートは省略可)
Referer
リクエストリンク元のURL (綴りは仕様上 Referer)--
[URL]
直前のページURL
User-Agent
リクエストクライアントソフトウェアの情報--
[名称/バージョン]
ブラウザ等の名称・バージョン・OS情報
Cookie
リクエストサーバから受け取ったCookieを返送する (複数は ; 区切り)--
[name]=[value]; ...
返送するCookie名と値
 
Accept
リクエスト受信可能なメディアタイプ
(コンマ区切りで複数列挙)		--
text/html
HTML文書
--
application/xml
XML文書
--
*/*
すべてのメディアタイプ
q
優先度 (品質値)
省略時 : 1.0
大きいほど優先)
0.0 ～ 1.0
優先度 (例: text/html;q=0.9)
 
Accept-Language
リクエスト受信可能な言語
(言語タグをコンマ区切りで列挙)		--
ja-JP
日本語 (日本)
--
ja
日本語
--
en-US
英語 (米国)
--
en
英語
q
言語ごとの優先度
0.0 ～ 1.0
優先度 (例: ja;q=0.9,en-US;q=0.8)
 
Accept-Encoding
リクエスト対応している圧縮形式
(コンマ区切り)		--
gzip
gzip圧縮に対応
--
deflate
deflate圧縮に対応
--
br
Brotli圧縮に対応
--
zstd
Zstandard圧縮に対応
q
圧縮形式ごとの優先度
0.0 ～ 1.0
優先度 (例: gzip;q=0.8)
Upgrade-Insecure-Requests
リクエストHTTPSへのアップグレード要求--
1
HTTPSでの取得を優先して欲しい意思表示
If-Modified-Since
リクエストキャッシュ検証 (日時)
以降に更新されていなければ 304 を返す		--
[ddd, dd MMM yyyy HH:mm:ss GMT]
更新確認の基準日時
If-None-Match
リクエストキャッシュ検証 (ETag)
一致すれば 304 を返す		--
[ETag値]
キャッシュ済みのETag
If-Match
リクエスト更新の前提条件 (楽観ロック)
一致しなければ 412 を返す		--
[ETag値]
更新対象の期待するETag
Range
リクエストボディの一部のみ要求 (部分取得)
成功時は 206 Partial Content		--
bytes=[開始]-[終了]
取得するバイト範囲
X-Forwarded-For
リクエストプロキシ/LB経由時の送信元情報--
[client], [proxy1], ...
実際の送信元IPアドレス (左端がクライアント)
X-Forwarded-Proto
リクエストプロキシ/LB経由前のプロトコル--
http
HTTPで受信
--
https
HTTPSで受信
X-Forwarded-Host
リクエストプロキシ/LB経由前の Host--
[host]
元のホスト名
 
X-Requested-With
リクエストXHRによるリクエストの識別
jQuery等が付与
Fetch APIは付与しない
サーバ側でAjax判定に利用
CSRF対策としては単独で不十分		--
XMLHttpRequest
XHRによるリクエストを示す固定値
X-CSRF-Token
リクエストCSRF対策トークン (XHR/Fetchで付与する慣例)
フレームワークにより名称が異なる (X-XSRF-TOKEN 等)		--
[トークン]
サーバが発行したCSRFトークン
Origin
リクエストリクエスト発行元のオリジン (CORS / POSTで付与)
CSRF検証にも利用		--
[scheme]://[host]:[port]
パスを含まないオリジン
Access-Control-Request-Method
リクエスト本リクエストで使うメソッドの事前通知 (プリフライト)--
[method]
使用予定のHTTPメソッド (例: PUT)
Access-Control-Request-Headers
リクエスト本リクエストで使う独自ヘッダの事前通知 (プリフライト)
コンマ区切り		--
[ヘッダ名], ...
使用予定のヘッダ名 (例: content-type, x-requested-with)
Sec-Fetch-Site
リクエスト発行元との関係
ブラウザが自動付与
改竄不可
CSRF対策の判定材料		--
same-origin
同一オリジン
--
same-site
同一サイト (オリジンは異なる)
--
cross-site
別サイト
--
none
ユーザ操作による直接アクセス
Sec-Fetch-Mode
リクエストリクエストのモード--
cors
CORSリクエスト (XHR / fetch は主にこれ)
--
navigate
ページ遷移
--
no-cors
CORSなしのリクエスト (画像・スクリプト読込等)
--
same-origin
同一オリジン限定のリクエスト
Sec-Fetch-Dest
リクエスト取得結果の用途--
document
HTML文書として使用
--
script
スクリプトとして使用
--
image
画像として使用
--
empty
XHR / fetch で使用
 
Server
レスポンス処理したWebサーバの種類 (バージョン秘匿推奨)--
[名称/バージョン]

[URI]

(コンマ区切り)		--

[ヘッダ名]
