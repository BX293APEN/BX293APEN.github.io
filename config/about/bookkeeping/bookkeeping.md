# 表記ルール

* 表の列は 用語 説明 計算式 備考 タグ の5列
* 見出しの階層が分類になる (`##` が大分類 `###` が分類 `###` は省略可で その場合は `##` の直下に表を置く)
* 計算式列は TeX 形式 (flalign) を div で囲んで記載
* 仕訳は (借)借方科目 / (貸)貸方科目 の形式
* 不要な欄は -
* 同じ用語は1行にまとめる (行は最初に出てくる見出しの下に置く)
* タグ列は 見出し以外で決まるタグを コンマ(,) 区切りで記載 (なければ -)
    * 特徴タグ: 計算式あり (計算式列が - でない) / 仕訳あり ((借) を含む) / 評価勘定
    * 見出しの名前: 用語が別の見出しの下にも属するとき その見出し名 (`###` の名前 `###` がなければ `##` の名前)

| 決算 | 会計期間末に帳簿を締め切り財務諸表を作成する手続き | - |  | 決算手続き |

| 勘定記入のルール | 資産と費用は借方に増加を記入 負債 純資産 収益は貸方に増加を記入 | - | 5つの要素と増減ルールを参照 | - |
| 取引の結合関係 | 借方の要素と貸方の要素の組み合わせ | - | <ul><li>例: 資産の増加と資産の減少</li><li>資産の増加と負債の増加</li><li>費用の発生と資産の減少</li><li>資産の増加と収益の発生</li></ul> | - |
| 取引の種類 | 取引は性質によって3つに分類される | - | <ul><li>交換取引</li><li>損益取引</li><li>混合取引</li></ul> | - |
| 交換取引 | 資産 負債 純資産の増減だけで 収益と費用が生じない取引 | - | 例: 現金で備品を購入 (借)備品 / (貸)現金 | 仕訳あり |
| 損益取引 | 収益または費用が発生して 純資産が増減する取引 | - | 例: 給料を現金で支払う (借)給料 / (貸)現金 | 仕訳あり |
| 混合取引 | 交換取引と損益取引が1つの取引に混在するもの | - | 例: 借入金と利息を現金で返済 (借)借入金 支払利息 / (貸)現金 | 仕訳あり |
| 財産法 | 期末と期首の純資産の差額から利益を求める方法 | <div class="boki-formula">\[\begin{flalign}& 当期純利益 = 期末純資産 - 期首純資産 &\end{flalign}\]</div> | 追加出資や引出しがない場合 | 計算式あり |
| 損益法 | 収益と費用の差額から利益を求める方法 | <div class="boki-formula">\[\begin{flalign}& 当期純利益 = 総収益 - 総費用 &\end{flalign}\]</div> | - | 計算式あり |

### 5つの要素と増減ルール

| 用語 | 説明 | 計算式 | 備考 | タグ |
|---|---|---|---|---|
| 資産 | <ul><li>簿記の5要素の一つ</li><li>会社が持つ財産 (他人の金と自分の金で調達したもの)</li><li>貸借対照表に記入する</li></ul> | <div class="boki-formula">\[\begin{flalign}& 資産 = 負債(他人の金) + 純資産(自分の金) \\ & = 流動資産 + 有形固定資産 + 無形固定資産 + 投資その他の固定資産 + 繰延資産 &\end{flalign}\]</div> | <ul><li>例: 現金 預金 売掛金 建物 備品</li><li>増加は借方 減少は貸方</li></ul> | 計算式あり, 資産 (Assets)の勘定, 財務三表の基本構造, 表あり |
| 負債 | <ul><li>簿記の5要素の一つ</li><li>将来支払う義務(返済義務のある債務の合計)</li><li>貸借対照表に記入する</li></ul> | <div class="boki-formula">\[\begin{flalign}& 負債 = 流動負債 + 固定負債 &\end{flalign}\]</div> | <ul><li>例: 買掛金 借入金 未払金</li><li>増加は貸方 減少は借方</li></ul> | 計算式あり, 負債 (Liabilities)の勘定, 財務三表の基本構造, 表あり |
| 純資産(資本) | <ul><li>簿記の5要素の一つ</li><li>資産から負債を引いた会社の正味財産</li><li>貸借対照表に記入する</li></ul> | <div class="boki-formula">\[\begin{flalign}& 純資産 = 資本金 + 資本剰余金 + 利益剰余金 - 自己株式 \\ & + 評価換算差額金 + 新株予約権 + 非支配株主持分 &\end{flalign}\]</div> | 増加は貸方 減少は借方 | 計算式あり, 純資産 (Net Assets)の勘定, 財務三表の基本構造, 表あり |
| 収益 | <ul><li>簿記の5要素の一つ</li><li>純資産を増やす要因</li><li>損益計算書に記入する</li></ul> | - | <ul><li>例: 売上 受取利息 受取手数料</li><li>発生は貸方 消滅は借方</li></ul> | 表あり |
| 費用 | <ul><li>簿記の5要素の一つ</li><li>純資産を減らす要因</li><li>損益計算書に記入する</li></ul> | - | <ul><li>例: 仕入 給料 支払家賃 広告宣伝費</li><li>発生は借方 消滅は貸方</li></ul> | 表あり |
| 貸借対照表等式 | 資産と負債と純資産の関係 | <div class="boki-formula">\[\begin{flalign}& 資産 = 負債 + 純資産 &\end{flalign}\]</div> | 貸借対照表の基本形 | 計算式あり |
| 損益計算書等式 | 収益と費用と当期純利益の関係 | <div class="boki-formula">\[\begin{flalign}& 当期純利益 = 収益 - 費用 &\end{flalign}\]</div> | マイナスなら当期純損失 | 計算式あり |
| 資本等式 | 資産から負債を引くと純資産になる | <div class="boki-formula">\[\begin{flalign}& 純資産 = 資産 - 負債 &\end{flalign}\]</div> | - | 計算式あり |
| 損益等式 | 収益から費用を引くと利益(資本を増やす金額)になる | <div class="boki-formula">\[\begin{flalign}& 利益 = 収益 - 費用 &\end{flalign}\]</div> | - | 計算式あり |
| 当期純損失 | 費用が収益を上回った場合の差額 | <div class="boki-formula">\[\begin{flalign}& 当期純損失 = 費用 - 収益 &\end{flalign}\]</div> | - | 計算式あり |
| 財政状態 | <ul><li>企業に 現在(一定時点)、何がいくらあるのかを表す</li><li>資産 負債 純資産の状況</li></ul> | - | 貸借対照表で表す | - |
| 経営成績 | <ul><li>企業が一定期間にどんな活動をし、その結果いくらもらったのか又は損をしたのかを表す</li><li>収益 費用と損益の状況</li></ul> | - | 損益計算書で表す | - |
| 損益計算書と貸借対照表の関係 | 当期純損益は両方の表に現れてつながる | <div class="boki-formula">\[\begin{flalign}& 期末純資産 = 期首純資産 + 当期純利益 \quad (追加出資や配当がない場合) &\end{flalign}\]</div> | <ul><li>損益計算書の当期純利益は 貸借対照表の純資産に加算される (繰越利益剰余金 個人事業は資本金)</li></ul> | 計算式あり |

### 収益性分析

| 用語 | 説明 | 計算式 | 備考 | タグ |
|---|---|---|---|---|
| ROI (Return On Investment 投資利益率) | 投じた資金に対する利益の割合 | <div class="boki-formula">\[\begin{flalign}& ROI = \dfrac{利益}{投資額} \times 100 &\end{flalign}\]</div> | <ul><li>対象範囲が柔軟 (会社全体にも個別施策にも使う)</li><li>プロジェクト単位や広告等 対象を限定して使うことが多い</li></ul> | 計算式あり |
| ROE (Return On Equity 自己資本利益率) | 株主が出した資本でどれだけ利益を稼いだか | <div class="boki-formula">\[\begin{flalign}& ROE = \dfrac{当期純利益}{自己資本} \times 100 \\ & = 売上高純利益率 \times 総資産回転率 \times 財務レバレッジ &\end{flalign}\]</div> | 財務諸表全体の指標として使われる | 計算式あり |
| ROA (Return On Assets 総資産利益率) | 負債も含めた総資産全体の運用効率 | <div class="boki-formula">\[\begin{flalign}& ROA = \dfrac{当期純利益}{総資産} \times 100 &\end{flalign}\]</div> | 財務諸表全体の指標として使われる | 計算式あり |
| ROAS (Return On Advertising Spend 広告費用対効果) | 投じた広告費に対する売上の割合 | <div class="boki-formula">\[\begin{flalign}& ROAS = \dfrac{広告経由の売上}{広告費} \times 100 &\end{flalign}\]</div> | 利益ではなく売上ベースな点に注意 | 計算式あり |
| TCO (Total Cost of Ownership 総所有費用) | 導入から運用と廃棄までの全期間にかかる費用の総額 | <div class="boki-formula">\[\begin{flalign}& TCO = 初期費用 + \sum_{t=1}^{n} 運用費用_t (+ 廃棄費用) &\end{flalign}\]</div> | <ul><li>購入価格だけでなく保守 人件費 教育費等も含めて比較する</li><li>費用側のみの評価 (低いほど良い)</li></ul> | 計算式あり |
| TB (Total Benefits 総便益) | 投資や導入によって得られる効果を金額に換算した合計 | <div class="boki-formula">\[\begin{flalign}& TB = \sum_{t=1}^{n} 便益_t &\end{flalign}\]</div><div class="boki-formula">\[\begin{flalign}& TB(現在価値) = \sum_{t=1}^{n} \dfrac{便益_t}{(1+r)^t} &\end{flalign}\]</div> | <ul><li>売上増加 コスト削減 業務効率化による工数削減等</li><li>TCO (総費用) の対となる指標</li><li>現在価値で比較する場合は下側の式</li></ul> | 計算式あり |
| TVO (Total Value of Ownership 総所有価値) | TCO (費用) に加えて得られる便益 (価値) も評価する指標 | <div class="boki-formula">\[\begin{flalign}& TVO = 総便益 - TCO &\end{flalign}\]</div> | <ul><li>費用だけでなく効果まで含めて比較できる</li><li>定義は文献により異なる</li></ul> | 計算式あり |
| TEI (Total Economic Impact 総経済効果) | Forrester社が提唱する投資評価の手法 | <div class="boki-formula">\[\begin{flalign}& TEI = PV(リスク調整後便益) + PV(柔軟性) - PV(リスク調整後コスト) &\end{flalign}\]</div><div class="boki-formula">\[\begin{flalign}& PV : 現在価値 &\end{flalign}\]</div> | <ul><li>便益 コスト 柔軟性 リスクの4要素で評価する</li><li>算出したNPVやROIを投資判断に用いる</li></ul> | 計算式あり |
| PP (Payback Period 投資回収期間) | 投資額を回収するのに必要な期間 (短いほど良い) | <div class="boki-formula">\[\begin{flalign}& PP = \dfrac{初期投資額}{年間回収額 (年間CF)} [年] &\end{flalign}\]</div> | <ul><li>年ごとにCFが異なる場合は累積CFが0を超える年で求める</li><li>貨幣の時間価値を考慮しない</li></ul> | 計算式あり |
| NPV (Net Present Value 正味現在価値) | 将来のCFを割引率で現在価値に直した合計から投資額を引いた値 | <div class="boki-formula">\[\begin{flalign}& NPV = \sum_{t=1}^{n} \dfrac{CF_t}{(1+r)^t} - 初期投資額 &\end{flalign}\]</div><div class="boki-formula">\[\begin{flalign}& CF_t : t年目のキャッシュフロー \\ & r : 割引率 (資本コスト) &\end{flalign}\]</div> | <ul><li>NPV > 0 なら投資価値あり (大きいほど良い)</li><li>貨幣の時間価値を考慮する</li></ul> | 計算式あり |
| IRR (Internal Rate of Return 内部収益率) | 投資の期待収益率 | <div class="boki-formula">\[\begin{flalign}& \sum_{t=1}^{n} \dfrac{CF_t}{(1+IRR)^t} - 初期投資額 = 0 &\end{flalign}\]</div> | <ul><li>NPV = 0 となる割引率が IRR</li><li>IRR > 資本コスト (要求収益率) なら投資価値あり (高いほど良い)</li></ul> | 計算式あり |
| 売上高総利益率 | 粗利率 | <div class="boki-formula">\[\begin{flalign}& 売上高総利益率 = \dfrac{売上総利益}{売上高} \times 100 &\end{flalign}\]</div> | - | 計算式あり |
| 売上高営業利益率 | 本業の稼ぐ力 | <div class="boki-formula">\[\begin{flalign}& 売上高営業利益率 = \dfrac{営業利益}{売上高} \times 100 &\end{flalign}\]</div> | - | 計算式あり |
| 売上高経常利益率 | 財務活動込みの収益力 | <div class="boki-formula">\[\begin{flalign}& 売上高経常利益率 = \dfrac{経常利益}{売上高} \times 100 &\end{flalign}\]</div> | - | 計算式あり |

### 不確実性下の意思決定基準

| 用語 | 説明 | 計算式 | 備考 | タグ |
|---|---|---|---|---|
| マクシマックス基準 (Maximax criterion) | 各案の最大利得の中から最も大きいものを選ぶ | <div class="boki-formula">\[\begin{flalign}& \max_{i} \left( \max_{j} a_{ij} \right) &\end{flalign}\]</div> | <ul><li>別名: 楽観主義基準</li><li>強気 (best of best)</li><li>強気で楽観的な意思決定者向け</li></ul> | 計算式あり |
| マクシミン基準 (Maximin criterion) | 各案の最小利得の中から最も大きいものを選ぶ | <div class="boki-formula">\[\begin{flalign}& \max_{i} \left( \min_{j} a_{ij} \right) &\end{flalign}\]</div> | <ul><li>別名: ワルドの基準 悲観主義基準</li><li>弱気 (best of worst)</li><li>最悪の事態を想定した安全志向の基準</li></ul> | 計算式あり |
| ミニマックス リグレット基準 (Minimax regret criterion) | 各状況で選ばなかったことによる後悔 (機会損失) を求め その最大後悔が最も小さい案を選ぶ | <div class="boki-formula">\[\begin{flalign}& r_{ij} = \max_{k} a_{kj} - a_{ij} \\ & \min_{i} \left( \max_{j} r_{ij} \right) &\end{flalign}\]</div> | 別名: サベージの基準 | 計算式あり |
| ハーヴィッツ基準 (Hurwicz criterion) | 楽観度αを用いて加重平均が最大の案を選ぶ (マクシマックスとマクシミンの折衷) | <div class="boki-formula">\[\begin{flalign}& 楽観度 = \alpha \quad (0 \le \alpha \le 1) &\end{flalign}\]</div><div class="boki-formula">\[\begin{flalign}& \alpha \times 最大利得 + (1-\alpha) \times 最小利得 &\end{flalign}\]</div> | 別名: 楽観係数基準 | 計算式あり |
| ラプラス基準 (Laplace criterion) | 各状況が同じ確率で起こると仮定し 期待値が最大の案を選ぶ | <div class="boki-formula">\[\begin{flalign}& 期待値 = \dfrac{1}{n} \sum_{j=1}^{n} a_{ij} &\end{flalign}\]</div> | <ul><li>別名: 等確率基準</li><li>別名: 理由不十分の原則</li></ul> | 計算式あり |
| 期待値基準 (Expected value criterion) | 各状況の発生確率が既知の場合に 期待利得が最大の案を選ぶ | <div class="boki-formula">\[\begin{flalign}& 期待利得 = \sum_{j} p_j \times a_{ij} &\end{flalign}\]</div> | - | 計算式あり |
