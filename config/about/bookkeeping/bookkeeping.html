取引の種類
 取引は性質によって3つに分類される —
  • 交換取引
  • 損益取引
  • 混合取引
交換取引
 資産 負債 純資産の増減だけで 収益と費用が生じない取引 — 例: 現金で備品を購入 (借)備品 / (貸)現金
損益取引
 収益または費用が発生して 純資産が増減する取引 — 例: 給料を現金で支払う (借)給料 / (貸)現金
混合取引
 交換取引と損益取引が1つの取引に混在するもの — 例: 借入金と利息を現金で返済 (借)借入金 支払利息 / (貸)現金
財産法
 期末と期首の純資産の差額から利益を求める方法
\[\begin{flalign}& 当期純利益 = 期末純資産 - 期首純資産 &\end{flalign}\]
 追加出資や引出しがない場合
損益法
 収益と費用の差額から利益を求める方法
\[\begin{flalign}& 当期純利益 = 総収益 - 総費用 &\end{flalign}\]

売上原価対立法
 販売のつど売上原価勘定に振り替える方法
\[\begin{flalign}& 売上原価 = 払出数量 \times 払出単価 &\end{flalign}\]
  • 仕入時: (借)商品 / (貸)買掛金
  • 販売時: (借)売掛金 / (貸)売上 と (借)売上原価 / (貸)商品
  • 決算での売上原価の整理仕訳は不要

\[\begin{flalign}& 残高数量 = 前残高数量 + 受入数量 - 払出数量 &\end{flalign}\]
\[\begin{flalign}& 残高金額 = 前残高金額 + 受入金額 - 払出金額 &\end{flalign}\]
 —
商品有高帳の記入上の注意
 払出欄は売価ではなく 仕入原価 (払出単価) で記入する
\[\begin{flalign}& 売上総利益 = 売上高 - 払出原価 &\end{flalign}\]
  • 仕入諸掛は受入単価に含める
  • 受入欄 払出欄 残高欄にそれぞれ数量 単価 金額を記入
  • 払出単価を先入先出法と移動平均法のどちらで求めるかは問題の指示に従う

現金過不足の原因判明

 銀行に手形代金の回収を依頼する行為 —

電子記録債務の発生
 買掛金を電子記録債務へ振替 — (借)買掛金 / (貸)電子記録債務

 電子記録債権を他人へ譲渡 — 譲渡記録を行う

 代金が決済され債権が消滅 — 当座預金等に入金

 満期日に手形代金が支払われないこと —

差額補充法
 設定額と残高の差額だけ追加で繰り入れる方法
\[\begin{flalign}& 繰入額 = 貸倒見積額 - 貸倒引当金の残高 &\end{flalign}\]
 標準的な方法

 前期から繰り越した債権が貸倒れた場合 —

  • 不足分は貸倒損失

 貸倒引当金がなく当期の債権が貸倒れた場合 — (借)貸倒損失 / (貸)売掛金
貸倒引当金の対象債権
 売掛金 受取手形 電子記録債権 貸付金など — 貸倒引当金は債権から控除する評価勘定として貸借対照表に表示

 売却額と帳簿価額の差額を処理

 決算時に時価に修正

  • 有価証券評価益(収益)
  • 有価証券評価損(費用)

 国債や社債の利息 —

取得原価
 購入代価に付随費用を加えた額
\[\begin{flalign}& 取得原価 = 購入代価 + 付随費用 &\end{flalign}\]

減価償却
 固定資産の価値の減少を費用として配分する手続き (期間損益計算) —
  • 土地は対象外
  • 決算整理で費用を計上
定額法
 毎年同額を償却する方法
\[\begin{flalign}& 年間減価償却費 = \dfrac{取得原価 - 残存価額}{耐用年数} &\end{flalign}\]
 —
残存価額
 耐用年数経過後に残ると見込まれる価額
\[\begin{flalign}& 残存価額 = 取得原価 \times 残存率 &\end{flalign}\]
 取得原価の10%など
残存価額がゼロの場合
 残存価額を0として 取得原価の全額を償却する
\[\begin{flalign}& 年間減価償却費 = \dfrac{取得原価}{耐用年数} &\end{flalign}\]
 問題文に「残存価額はゼロ」と指示される
耐用年数
 固定資産を使用できると見込まれる年数 — —
月割計算
 期中に取得または売却した場合は月数で按分
\[\begin{flalign}& 当期減価償却費 = 年間減価償却費 \times \dfrac{使用月数}{12} &\end{flalign}\]
 1年未満の場合
直接法
 固定資産の帳簿価額を直接減らす記帳方法 — (借)減価償却費 / (貸)固定資産
間接法
 減価償却累計額を設けて間接的に減らす方法 — (借)減価償却費 / (貸)減価償却累計額
帳簿価額(簿価)
 取得原価から減価償却累計額を引いた額
\[\begin{flalign}& 帳簿価額 = 取得原価 - 減価償却累計額 &\end{flalign}\]
 —
資本的支出
 固定資産の価値を高める支出 — 固定資産の取得原価に加算
収益的支出
 現状維持のための支出 — 修繕費(費用)
固定資産の購入
 取得原価で記帳し代金は現金や未払金などで処理 — (借)備品 / (貸)未払金
固定資産の売却
 売却時点までの減価償却費を計上してから売却処理
\[\begin{flalign}& 売却損益 = 売却価額 - 帳簿価額 &\end{flalign}\]
  • (借)減価償却累計額 未収入金 固定資産売却損 / (貸)固定資産 固定資産売却益
  • 期中の売却は売却月までの月割の減価償却を計上
未償却残高
 取得原価から減価償却累計額を引いた額
\[\begin{flalign}& 未償却残高 = 取得原価 - 減価償却累計額 &\end{flalign}\]
 帳簿価額と同じ
定率法
 期首の未償却残高に一定の償却率をかけて償却する方法
\[\begin{flalign}& 年間減価償却費 = (取得原価 - 期首の減価償却累計額) \times 償却率 &\end{flalign}\]
  • 償却率は問題で与えられる簡易な計算
定率法の計算例
 償却率は問題で与えられる簡易な計算
\[\begin{flalign}& 取得原価 700{,}000 \quad 期首の減価償却累計額 448{,}000 \quad 償却率 0.4 \\ & 減価償却費 = (700{,}000 - 448{,}000) \times 0.4 = 100{,}800 &\end{flalign}\]
  • (借)減価償却費 / (貸)減価償却累計額
  • 200%定率法の保証率や改定償却率は扱わない
定額法の償却率
 毎年同じ割合で償却する場合の率
\[\begin{flalign}& 償却率 = \dfrac{1}{耐用年数} &\end{flalign}\]

 使用をやめて固定資産を帳簿から外す
\[\begin{flalign}& 固定資産除却損 = 帳簿価額 - 処分価値 &\end{flalign}\]

固定資産の廃棄
 不用な固定資産を捨てる
\[\begin{flalign}& 固定資産廃棄損 = 帳簿価額 + 廃棄費用 &\end{flalign}\]

  • 貸方の現金は廃棄費用の支払い
消費税
 商品販売等にかかる税
\[\begin{flalign}& 税込価額 = 税抜価額 \times (1 + 消費税率) &\end{flalign}\]
\[\begin{flalign}& 税抜価額 = \dfrac{税込価額}{1 + 消費税率} &\end{flalign}\]
 税抜方式と税込方式がある
所得税(個人事業)
 事業主個人が負担する税金 — 事業の費用とせず引出金で処理
住民税(個人事業)
 事業主個人が負担する住民税 — 事業の費用とせず引出金で処理
事業税(個人事業)
 個人事業の所得にかかる事業税 —
  • (借)租税公課 / (貸)現金
  • 法人の事業税は法人税等に含める
源泉所得税
 従業員の給料から差し引いて預かる所得税 — 預り金として処理し後日納付
社会保険料
 健康保険や厚生年金保険などの保険料 —
  • 従業員負担分は預り金
  • 会社負担分は法定福利費(費用)

 総額から控除額を引いた手取額を支払う
\[\begin{flalign}& 手取額 = 総支給額 - 源泉所得税 - 社会保険料(従業員負担分) - 立替金など &\end{flalign}\]
  • (借)給料 / (貸)預り金 現金
  • 預り金は源泉所得税等

 従業員の福利厚生のための支出 — 費用
受取保証金
 預かった保証金 — 負債
消費税額の計算
 税抜価額に税率をかけた額
\[\begin{flalign}& 消費税額 = 税抜価額 \times 消費税率 &\end{flalign}\]
\[\begin{flalign}& 税込価額 = 税抜価額 + 消費税額 &\end{flalign}\]
 —

 消費税を仕入や売上に含めて処理する方法 — 税込価額をそのまま仕入や売上に記帳
消費税の納付

収入印紙
 印紙税を納付するための印紙 —
  • 購入時: (借)租税公課 / (貸)現金
  • 未使用分は決算で貯蔵品に振替
固定資産税
 固定資産にかかる地方税 — (借)租税公課 / (貸)現金 未払金
法人税等の中間申告
 期中に概算で納付 — (借)仮払法人税等 / (貸)現金 当座預金
法人税等の確定
 決算で確定した税額との差額を未払計上 — (借)法人税等 / (貸)仮払法人税等 未払法人税等
源泉所得税の納付
 預かっていた源泉所得税を納付 — (借)預り金 / (貸)現金
社会保険料の納付
 預かった従業員負担分と会社負担分を納付 — (借)預り金 法定福利費 / (貸)現金
住民税の特別徴収
 従業員の住民税を給料から預かる — (借)給料 / (貸)預り金
資本準備金
 払込金額のうち資本金にしなかった部分
\[\begin{flalign}& 資本準備金 = 払込金額 - 資本金組入額 &\end{flalign}\]
 簡易な処理では発行価額の総額を資本金とする
当期純損益の振替
 決算で損益勘定の残高(当期純損益)を繰越利益剰余金へ振り替える —
  • 決算振替仕訳
  • 利益(貸方残高): (借)損益 / (貸)繰越利益剰余金
  • 損失(借方残高): (借)繰越利益剰余金 / (貸)損益
  • 個人事業は資本金へ
剰余金の配当
 株主への配当金支払い —
  • (借)繰越利益剰余金 / (貸)未払配当金 利益準備金
剰余金の処分
 当期純利益などを配当や準備金へ振り分けること —
  • 配当金と利益準備金の積立を扱う簡易な内容
配当金の支払い
 決議した配当金を株主へ支払う —
  • (借)未払配当金 / (貸)当座預金
株式の発行(増資)
 会社成立後に新株を発行して資本金を増やすこと
\[\begin{flalign}& 資本金の増加額 = 発行価額 \times 発行株式数 &\end{flalign}\]
  • (借)当座預金等 / (貸)資本金
  • 簡易な処理では発行価額の総額を資本金とする
株主資本
 純資産のうち株主に帰属する部分
\[\begin{flalign}& 株主資本 = 資本金 + 資本剰余金 + 利益剰余金 - 自己株式 &\end{flalign}\]
  • 資本金
  • 資本剰余金
  • 利益剰余金
  • 自己株式は株主への払い戻しとして控除する
株式会社の設立
 株式を発行して出資を受ける —
  • (借)当座預金 / (貸)資本金
  • 簡易な処理では発行価額の総額を資本金とする
追加元入れ
 事業主が事業へ資金を追加した場合 — (借)現金 / (貸)資本金
資本金への振替
 決算で引出金と当期純利益を資本金へ振替 — 個人事業では繰越利益剰余金は使わない
決算整理仕訳
 決算で帳簿の金額を正しく修正する仕訳 — —
売上原価の計算

\[\begin{flalign}& 売上原価 = 期首商品棚卸高 + 当期仕入高 - 期末商品棚卸高 &\end{flalign}\]

費用の前払い
 当期に支払ったが次期以降の費用が含まれている場合
\[\begin{flalign}& 前払費用 = 支払額 \times \dfrac{次期に属する月数}{支払対象の全月数} &\end{flalign}\]
  • (借)前払費用 / (貸)費用の科目
  • 例: (借)前払費用 / (貸)支払家賃等
費用の未払い

\[\begin{flalign}& 未払費用 = 月額費用 \times 当期に属する未払月数 &\end{flalign}\]
  • (借)費用の科目 / (貸)未払費用
  • 例: (借)支払利息等 / (貸)未払費用

  • (借)収益の科目 / (貸)前受収益
  • 例: (借)受取家賃等 / (貸)前受収益

ROI (Return On Investment 投資利益率)
 投じた資金に対する利益の割合
\[\begin{flalign}& ROI = \dfrac{利益}{投資額} \times 100 &\end{flalign}\]
  • 対象範囲が柔軟 (会社全体にも個別施策にも使う)
  • プロジェクト単位や広告等 対象を限定して使うことが多い
ROE (Return On Equity 自己資本利益率)
 株主が出した資本でどれだけ利益を稼いだか
\[\begin{flalign}& ROE = \dfrac{当期純利益}{自己資本} \times 100 \\ & = 売上高純利益率 \times 総資産回転率 \times 財務レバレッジ &\end{flalign}\]
 財務諸表全体の指標として使われる
ROA (Return On Assets 総資産利益率)
 負債も含めた総資産全体の運用効率
\[\begin{flalign}& ROA = \dfrac{当期純利益}{総資産} \times 100 &\end{flalign}\]
 財務諸表全体の指標として使われる
ROAS (Return On Advertising Spend 広告費用対効果)
 投じた広告費に対する売上の割合
\[\begin{flalign}& ROAS = \dfrac{広告経由の売上}{広告費} \times 100 &\end{flalign}\]
 利益ではなく売上ベースな点に注意
TCO (Total Cost of Ownership 総所有費用)
 導入から運用と廃棄までの全期間にかかる費用の総額
\[\begin{flalign}& TCO = 初期費用 + \sum_{t=1}^{n} 運用費用_t (+ 廃棄費用) &\end{flalign}\]
  • 購入価格だけでなく保守 人件費 教育費等も含めて比較する
  • 費用側のみの評価 (低いほど良い)
TB (Total Benefits 総便益)
 投資や導入によって得られる効果を金額に換算した合計
\[\begin{flalign}& TB = \sum_{t=1}^{n} 便益_t &\end{flalign}\]
\[\begin{flalign}& TB(現在価値) = \sum_{t=1}^{n} \dfrac{便益_t}{(1+r)^t} &\end{flalign}\]
  • 売上増加 コスト削減 業務効率化による工数削減等
  • TCO (総費用) の対となる指標
  • 現在価値で比較する場合は下側の式
TVO (Total Value of Ownership 総所有価値)
 TCO (費用) に加えて得られる便益 (価値) も評価する指標
\[\begin{flalign}& TVO = 総便益 - TCO &\end{flalign}\]
  • 費用だけでなく効果まで含めて比較できる
  • 定義は文献により異なる
TEI (Total Economic Impact 総経済効果)
 Forrester社が提唱する投資評価の手法
\[\begin{flalign}& TEI = PV(リスク調整後便益) + PV(柔軟性) - PV(リスク調整後コスト) &\end{flalign}\]
\[\begin{flalign}& PV : 現在価値 &\end{flalign}\]
  • 便益 コスト 柔軟性 リスクの4要素で評価する
  • 算出したNPVやROIを投資判断に用いる
PP (Payback Period 投資回収期間)
 投資額を回収するのに必要な期間 (短いほど良い)
\[\begin{flalign}& PP = \dfrac{初期投資額}{年間回収額 (年間CF)} [年] &\end{flalign}\]
  • 年ごとにCFが異なる場合は累積CFが0を超える年で求める
  • 貨幣の時間価値を考慮しない
NPV (Net Present Value 正味現在価値)
 将来のCFを割引率で現在価値に直した合計から投資額を引いた値
\[\begin{flalign}& NPV = \sum_{t=1}^{n} \dfrac{CF_t}{(1+r)^t} - 初期投資額 &\end{flalign}\]
\[\begin{flalign}& CF_t : t年目のキャッシュフロー \\ & r : 割引率 (資本コスト) &\end{flalign}\]
  • NPV > 0 なら投資価値あり (大きいほど良い)
  • 貨幣の時間価値を考慮する
IRR (Internal Rate of Return 内部収益率)
 投資の期待収益率
\[\begin{flalign}& \sum_{t=1}^{n} \dfrac{CF_t}{(1+IRR)^t} - 初期投資額 = 0 &\end{flalign}\]
  • NPV = 0 となる割引率が IRR
  • IRR > 資本コスト (要求収益率) なら投資価値あり (高いほど良い)

マクシマックス基準 (Maximax criterion)
 各案の最大利得の中から最も大きいものを選ぶ
\[\begin{flalign}& \max_{i} \left( \max_{j} a_{ij} \right) &\end{flalign}\]
  • 別名: 楽観主義基準
  • 強気 (best of best)
  • 強気で楽観的な意思決定者向け
マクシミン基準 (Maximin criterion)
 各案の最小利得の中から最も大きいものを選ぶ
\[\begin{flalign}& \max_{i} \left( \min_{j} a_{ij} \right) &\end{flalign}\]
  • 別名: ワルドの基準 悲観主義基準
  • 弱気 (best of worst)
  • 最悪の事態を想定した安全志向の基準
ミニマックス リグレット基準 (Minimax regret criterion)
 各状況で選ばなかったことによる後悔 (機会損失) を求め その最大後悔が最も小さい案を選ぶ
\[\begin{flalign}& r_{ij} = \max_{k} a_{kj} - a_{ij} \\ & \min_{i} \left( \max_{j} r_{ij} \right) &\end{flalign}\]
 別名: サベージの基準
ハーヴィッツ基準 (Hurwicz criterion)
 楽観度αを用いて加重平均が最大の案を選ぶ (マクシマックスとマクシミンの折衷)
\[\begin{flalign}& 楽観度 = \alpha \quad (0 \le \alpha \le 1) &\end{flalign}\]
\[\begin{flalign}& \alpha \times 最大利得 + (1-\alpha) \times 最小利得 &\end{flalign}\]
 別名: 楽観係数基準
ラプラス基準 (Laplace criterion)
 各状況が同じ確率で起こると仮定し 期待値が最大の案を選ぶ
\[\begin{flalign}& 期待値 = \dfrac{1}{n} \sum_{j=1}^{n} a_{ij} &\end{flalign}\]
  • 別名: 等確率基準
  • 別名: 理由不十分の原則
期待値基準 (Expected value criterion)
 各状況の発生確率が既知の場合に 期待利得が最大の案を選ぶ
\[\begin{flalign}& 期待利得 = \sum_{j} p_j \times a_{ij} &\end{flalign}\]
