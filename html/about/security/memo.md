
## 1. ITガバナンス関連

| 用語 | 説明 |
| --- | --- |
| ITガバナンス | 経営陣が主体となり、IT戦略の策定・実行を統制・監視する仕組み。企業統治(コーポレートガバナンス)の一部 |
| COBIT | ITガバナンスとIT統制のフレームワーク。ISACAが策定。「ガバナンス」と「マネジメント」を明確に分離 |
| IT戦略 | 経営戦略と整合させたIT投資・活用の方針。中長期計画に基づき策定される |
| IT投資評価 | IT投資が経営目標に対して適切な効果を生んでいるかを評価するプロセス |
| バランススコアカード(BSC) | 財務・顧客・業務プロセス・学習と成長の4視点で組織の業績を評価する手法 |
| IT委員会 | 経営層がIT戦略・投資・リスクを審議する組織体 |
| CIO | 最高情報責任者。IT戦略の統括責任者 |
| CISO | 最高情報セキュリティ責任者。情報セキュリティ全般の統括責任者 |
CSA

## 2. 内部統制関連

| 用語 | 説明 |
| --- | --- |
| 内部統制 | 業務の有効性・効率性、財務報告の信頼性、法令遵守、資産の保全の4目的を達成するための仕組み |
| COSOフレームワーク | 内部統制の国際的な標準フレームワーク。統制環境・リスク評価・統制活動・情報と伝達・モニタリングの5要素で構成 |
| J-SOX法(金融商品取引法) | 日本版SOX法。上場企業に財務報告に係る内部統制の評価・報告を義務付ける制度 |
| IT全般統制(ITGC) | 業務処理統制を支える基盤となる統制。システム開発・変更管理・アクセス管理・運用管理など |
| 業務処理統制(ITAC) | 個々の業務プロセス(入力・処理・出力)における自動化された統制 |
| 職務分掌(SoD) | 不正防止のため、業務の実行・承認・記録などの職務を複数人で分離すること |
| モニタリング | 内部統制が有効に機能しているかを継続的または独立的に評価する活動 |
| 3ラインモデル(旧3ライン・ディフェンス) | 現業部門(第1線)・リスク管理部門(第2線)・内部監査部門(第3線)によるリスク管理体制 |



## 4. リスクマネジメント関連

| 用語 | 説明 |
| --- | --- |
| リスクアセスメント | リスクの特定・分析・評価を行うプロセス |
| リスク対応 | リスク回避・低減・移転・保有などの対応策を選択・実施すること |
| 残留リスク | リスク対応後もなお残るリスク |
| BCP(事業継続計画) | 災害等の緊急事態が発生した際に事業を継続・早期復旧するための計画 |
| BCM(事業継続マネジメント) | BCPの策定・維持・改善を含む継続的なマネジメント活動 |
| RTO(目標復旧時間) | 災害発生後、システムを復旧させるまでの目標時間 |
| RPO(目標復旧時点) | 災害発生時に許容できるデータ損失の時点(どこまで遡ってデータを復旧するか) |

## 5. 関連ガイドライン・基準

| 名称 | 概要 |
| --- | --- |
| ISMS(ISO/IEC 27001) | 情報セキュリティマネジメントシステムの国際規格 |
| ISO/IEC 38500 | ITガバナンスに関する国際規格 |
| ITIL | ITサービスマネジメントのベストプラクティス集 |
| サイバーセキュリティ経営ガイドライン | 経済産業省・IPAが策定する経営者向けサイバーセキュリティ対策指針 |
| NISTサイバーセキュリティフレームワーク | 米国NISTが策定するサイバーセキュリティ対策の枠組み(特定・防御・検知・対応・復旧) |
