# Linuxのシステムディレクトリ一覧

FHS (Filesystem Hierarchy Standard) に基づく主要ディレクトリと、その内容をまとめる。

## 1. 主要ディレクトリ

| パス | 名称・分類 | 内容 | 主な格納物 |
|------|-----------|------|-----------|
| `/` | ルートディレクトリ | すべてのファイルシステム階層の最上位 | `/bin`, `/etc`, `/home` など全ディレクトリ |
| `/bin` | 基本コマンド | 全ユーザーが使う必須コマンド(近年は`/usr/bin`へのシンボリックリンクが主流) | `ls`, `cp`, `mv`, `cat`, `bash` |
| `/sbin` | システム管理コマンド | 管理者向けの必須コマンド | `fsck`, `reboot`, `ip`, `mount` |
| `/boot` | ブート関連 | ブートローダとカーネルイメージ | `vmlinuz`, `initrd.img`, `grub/` |
| `/dev` | デバイスファイル | ハードウェアや擬似デバイスへのインターフェース | `sda`, `tty`, `null`, `zero`, `random` |
| `/etc` | 設定ファイル | システム全体の設定(静的なテキスト設定) | `passwd`, `fstab`, `hosts`, `ssh/` |
| `/home` | ユーザーホーム | 一般ユーザーの個人データと設定 | `/home/<user>/`, `.bashrc` |
| `/root` | root用ホーム | スーパーユーザーのホームディレクトリ | `.bashrc`, `.ssh/` |
| `/lib` | 共有ライブラリ | `/bin`, `/sbin` が必要とするライブラリ | `libc.so.6`, `modules/` |
| `/lib64` | 64bitライブラリ | 64bit用の共有ライブラリ | `ld-linux-x86-64.so.2` |
| `/media` | リムーバブルメディア | USBやCD-ROMの自動マウントポイント | `/media/<user>/USB` |
| `/mnt` | 一時マウント | 管理者が手動でマウントする場所 | 任意のマウント先 |
| `/opt` | オプションソフト | 独立した追加ソフトウェア | `google/`, `zoom/` |
| `/proc` | プロセス情報 | カーネルとプロセスの仮想ファイルシステム | `cpuinfo`, `meminfo`, `<PID>/` |
| `/sys` | システム情報 | デバイスやドライバの仮想ファイルシステム | `class/`, `devices/`, `block/` |
| `/run` | 実行時データ | 起動以降の一時的な実行時情報(tmpfs) | `*.pid`, `*.sock`, `utmp` |
| `/srv` | サービスデータ | サービスが提供するデータ | `www/`, `ftp/` |
| `/tmp` | 一時ファイル | 一時ファイル置き場(再起動で消える場合が多い) | 各種一時ファイル |
| `/usr` | ユーザーソフト | 読み取り専用のプログラム・ライブラリ群 | `bin/`, `lib/`, `share/`, `local/` |
| `/var` | 可変データ | 動作中に内容が変化するデータ | `log/`, `spool/`, `cache/`, `lib/` |
| `/lost+found` | 復旧用 | `fsck` が回収したファイル片の置き場 | 破損ファイルの断片 |

## 2. `/usr` の下位ディレクトリ

| パス | 内容 |
|------|------|
| `/usr/bin` | 一般ユーザー向けコマンド(大半のプログラム) |
| `/usr/sbin` | 管理者向けコマンド(非必須) |
| `/usr/lib` | `/usr/bin` 等のためのライブラリ |
| `/usr/include` | C/C++ のヘッダファイル |
| `/usr/share` | アーキテクチャ非依存の共有データ(man, doc, locale) |
| `/usr/local` | ローカルにインストールしたソフト(パッケージ管理外) |
| `/usr/src` | ソースコード(カーネルソース等) |

## 3. `/var` の下位ディレクトリ

| パス | 内容 |
|------|------|
| `/var/log` | システムログ(`syslog`, `messages`, `auth.log`) |
| `/var/spool` | 処理待ちデータ(メール、印刷キュー、cron) |
| `/var/cache` | アプリケーションのキャッシュ |
| `/var/lib` | アプリケーションの状態データ(DB等) |
| `/var/tmp` | 再起動後も残る一時ファイル |
| `/var/run` | `/run` へのシンボリックリンク |
| `/var/www` | Webサーバのドキュメントルート(ディストリビューション依存) |

## 4. `/dev` の主な特殊ファイル

| パス | 種別 | 動作 |
|------|------|------|
| `/dev/null` | キャラクタデバイス | 書き込んだデータはすべて破棄。読み込むと即座にEOF |
| `/dev/zero` | キャラクタデバイス | 読み込むと無限に `0x00` を返す |
| `/dev/random` | キャラクタデバイス | 乱数を返す(カーネルの乱数生成器) |
| `/dev/urandom` | キャラクタデバイス | 非ブロッキングの乱数を返す |
| `/dev/full` | キャラクタデバイス | 書き込むと常に `ENOSPC`(容量不足)エラー |
| `/dev/tty` | キャラクタデバイス | 現在のプロセスの制御端末 |
| `/dev/stdin` | シンボリックリンク | 標準入力(`/proc/self/fd/0`) |
| `/dev/stdout` | シンボリックリンク | 標準出力(`/proc/self/fd/1`) |
| `/dev/stderr` | シンボリックリンク | 標準エラー出力(`/proc/self/fd/2`) |
| `/dev/sda` | ブロックデバイス | 1台目のSCSI/SATAディスク |
| `/dev/sda1` | ブロックデバイス | 1台目ディスクの第1パーティション |
| `/dev/nvme0n1` | ブロックデバイス | 1台目のNVMe SSD |
| `/dev/loop0` | ブロックデバイス | ループバックデバイス |

## 5. `/etc` の主な設定ファイル

| パス | 内容 |
|------|------|
| `/etc/passwd` | ユーザーアカウント情報 |
| `/etc/shadow` | ハッシュ化されたパスワード(root専用) |
| `/etc/group` | グループ情報 |
| `/etc/fstab` | 起動時にマウントするファイルシステム |
| `/etc/hosts` | ホスト名とIPアドレスの対応 |
| `/etc/hostname` | ホスト名 |
| `/etc/resolv.conf` | DNSリゾルバ設定 |
| `/etc/sudoers` | sudo の権限設定 |
| `/etc/ssh/` | SSHサーバ・クライアント設定 |
| `/etc/systemd/` | systemd の設定 |
| `/etc/crontab` | 定期実行タスク |
| `/etc/profile` | ログインシェルの共通設定 |

## 6. `/proc` の主なエントリ

| パス | 内容 |
|------|------|
| `/proc/cpuinfo` | CPU情報 |
| `/proc/meminfo` | メモリ使用状況 |
| `/proc/version` | カーネルバージョン |
| `/proc/uptime` | 稼働時間 |
| `/proc/mounts` | マウント中のファイルシステム |
| `/proc/<PID>/` | 各プロセスの情報(`cmdline`, `status`, `fd/`) |
| `/proc/sys/` | カーネルパラメータ(sysctl) |

## 7. ディレクトリの性質の比較

| パス | 内容の変化 | 保存先 | 再起動後 |
|------|-----------|--------|---------|
| `/bin`, `/usr` | 静的(読み取り専用が基本) | ディスク | 保持 |
| `/etc` | 静的(管理者が変更) | ディスク | 保持 |
| `/home` | 可変(ユーザーデータ) | ディスク | 保持 |
| `/var` | 可変(ログ・キャッシュ) | ディスク | 保持 |
| `/tmp` | 可変(一時) | ディスク/tmpfs | 消える場合が多い |
| `/run` | 可変(実行時) | tmpfs(メモリ) | 消える |
| `/proc`, `/sys` | 動的(カーネル生成) | 仮想(メモリ) | 消える |
| `/dev` | 動的(udev生成) | 仮想(devtmpfs) | 再生成 |
