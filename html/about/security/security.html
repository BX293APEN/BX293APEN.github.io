サイバー攻撃

攻撃者の種類

| 種類 | 説明 | |---|---| | クラッカー | コンピュータやネットワークに不正侵入し、破壊・改ざん・情報窃取等の悪意ある行為を行う者
「ハッカー」は本来、高度な技術を持つ者を指す中立的な語であり、悪意ある行為者は「クラッカー」と呼ぶのが技術的には正しい(ただし一般には「ハッカー」が悪意ある意味でも使われる) | | スクリプトキディ | 自らは高度な技術を持たず、他者が作成した攻撃ツールやスクリプトを利用して攻撃を行う初心者的な攻撃者 | | ハクティビスト | 政治的・社会的な主張を目的として、Webサイト改ざんやDDoS攻撃等を行う攻撃者 | | ボットハーダー | マルウェアに感染させた多数の端末(ボット)からなるボットネットを構築・遠隔操作する攻撃者 | | 内部関係者(インサイダー) | 従業員・元従業員・委託先担当者等、正規のアクセス権を持つ立場を悪用して情報漏えいや破壊行為を行う者。金銭目的、恨み、過失など動機は様々 | | 犯罪組織(サイバー犯罪集団) | 金銭的利益を目的として組織的にランサムウェア配布、フィッシング、不正送金等を行う集団。RaaS(Ransomware as a Service)のように攻撃基盤自体を商品化する例もある | | 詐欺犯 | フィッシングやビジネスメール詐欺(BEC)など、心理的な誘導によって金銭や情報をだまし取ることを目的とする者 | | APT攻撃者(標的型攻撃者) | 特定の組織を標的に、長期間・持続的に潜伏しながら情報窃取や妨害を行う高度な攻撃者。国家関与主体が背後にいる場合が多い | | 国家関与主体(ネーションステートアクター) | 国家の支援・関与を受け、諜報活動・重要インフラ攻撃・サイバー戦を目的として活動する攻撃者。高度な技術力と資金力を持つ | | 産業スパイ | 競合企業の技術情報・営業情報等を不正に取得することを目的とする者 | | 内部告発者との違いに注意すべき者(悪意ある退職者等) | 解雇・処遇への不満等を動機に、退職前後に情報持ち出しやシステム破壊を行う者 |

| 検査方法 | 製品 | 内容 | | --- | --- | --- | | ペネトレーションテスト | - | 実際の攻撃者と同じ手法・手順でシステムに侵入を試み、脆弱性が実際に悪用可能かどうかを検証する実践的な検査 | | ポートスキャナ | Nmap | 対象ホストの各ポートに接続要求を送り、開いているポート(稼働しているサービス)を洗い出すツール | | ファジング | - | 想定外の値・不正な形式のデータ(ファズ)を大量に入力し、ソフトウェアの異常終了や未知の脆弱性を検出する手法 | | 脆弱性診断(脆弱性スキャナ) | - | 既知の脆弱性データベース(CVE 等)と照合し、対象システムに既知の脆弱性が存在しないかを網羅的に確認する検査 | | ソースコード診断(静的解析 / SAST) | SonarQube | プログラムを実行せずソースコードを解析し、脆弱性の原因となるコーディング上の欠陥を検出する手法 | | Webアプリケーション診断(動的解析/ DAST) | OWASP ZAP | 実際にアプリケーションを動作させ、外部からリクエストを送って脆弱性(SQLインジェクション、XSS 等)を検出する手法 | | 構成管理監査(コンフィグレーションチェック) | - | OS・ミドルウェアの設定値がセキュリティ基準(ベースライン)に適合しているかを確認する検査 | | リバースエンジニアリング | 逆コンパイラ
コールグラフ | ソフトウェアを解析し、ソースコードや設計情報がない状態から内部構造・動作原理・アルゴリズムを明らかにする手法

基本的な対策

| 対策カテゴリ | 代表例 | |---|---| | ネットワーク防御 | ファイアウォール、IDS/IPS、WAF、UTM、NDR | | エンドポイント防御 | アンチウイルス、EDR/XDR、資産管理、パッチ管理 | | 認証強化 | 多要素認証(MFA)、パスワードレス認証、特権アクセス管理(PAM) | | データ保護 | 暗号化、DLP、バックアップ(3-2-1ルール) | | 運用・組織対策 | SOC/CSIRT、脆弱性診断、インシデント対応計画、セキュリティ教育、脅威インテリジェンス | | ガバナンス | ISMS(ISO/IEC 27001)、リスクアセスメント、委託先管理、SBOM管理 |
