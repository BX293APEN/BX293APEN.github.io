情報セキュリティについて

サイバーセキュリティ

 電子的方式、磁気的方式その他人の知覚によっては認識することができない方式により記録され、又は発信され、伝送され、若しくは受信される情報の漏洩、滅失又は毀損の防止その他の当該情報の安全管理のために必要な措置並びに情報システム及び情報通信ネットワークの安全性及び信頼性の確保のために必要な措置が講じられ、その状態が適切に維持管理されていること

↳ 電子的方式等で記録・発信・伝送・受信される情報の漏洩・滅失・毀損の防止や、情報システム・情報通信ネットワークの安全性・信頼性を確保するために必要な措置

| 用語 | 内容 | | --- | --- | | オプトイン | 本人があらかじめ同意 (許諾) した場合に限り、情報の利用や送信 (メール配信等) を行う方式
特定電子メール法の原則的な規制方式 | | オプトアウト | 本人が拒否 (停止) の意思表示をしない限り、情報の利用や送信を行ってよい方式
個人情報保護法における第三者提供の例外規定等で用いられる | | サンプリング | 母集団の中から一部を抽出して調査・分析を行う統計的手法
全数調査に比べコストを抑えつつ全体の傾向を推定できる | | k-匿名化 | 個人情報の匿名化技術の一つで、任意のレコードについて同じ属性値を持つ人が
