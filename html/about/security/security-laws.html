情報セキュリティについて

サイバーセキュリティ

 電子的方式、磁気的方式その他人の知覚によっては認識することができない方式により記録され、又は発信され、伝送され、若しくは受信される情報の漏洩、滅失又は毀損の防止その他の当該情報の安全管理のために必要な措置並びに情報システム及び情報通信ネットワークの安全性及び信頼性の確保のために必要な措置が講じられ、その状態が適切に維持管理されていること

↳ 電子的方式等で記録・発信・伝送・受信される情報の漏洩・滅失・毀損の防止や、情報システム・情報通信ネットワークの安全性・信頼性を確保するために必要な措置

システム監査人

システム監査を行う人、またはその職業

  • 独立性 : システム監査人が監査対象から独立した立場であること(外観上の独立性・精神上の独立性)
  • 専門的能力 : システム監査を適切に実施するために必要な知識・技能・経験を有していること。継続的な自己研鑽が求められる
  • 正当な注意義務 : 監査の実施にあたり、監査人として通常期待される程度の注意深さと専門的な判断をもって職務にあたること
  • 職業倫理と誠実性 : 監査人としての職責を自覚し、公正・誠実に職務を遂行すること。守秘義務の遵守もこれに含まれる
