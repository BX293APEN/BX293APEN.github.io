**PFS(Perfect Forward Secrecy : 前方秘匿性)**

<ul>
    <li>長期鍵(サーバの秘密鍵等)が将来漏洩しても、<br>過去に交換したセッション鍵・通信内容が復元されない性質</li>
    <li>セッションごとに一時的な鍵ペア(Ephemeral鍵)を生成し、<br>通信終了後に破棄することで実現する</li>
    <li>同じ鍵ペアを使い回す静的(Static)なDH/ECDHでは実現できない<br>(長期鍵の漏洩により過去の全セッションが復元される)</li>
</ul>

<br>
<br>

**量子鍵配送(QKD)の補足**

<ul>
    <li>QKDは「鍵を安全に共有する」技術であり、データの暗号化自体は別途AESやワンタイムパッド等で行う</li>
    <li>量子状態は測定すると乱れるため、盗聴があると誤り率が上昇し、検知できる</li>
    <li>
        古典チャネルの認証が別途必要<br>
        事前共有鍵やPQC署名等を用いる<br>
        認証が破られると中間者攻撃を受ける
    </li>
    <li>専用の量子通信機器が必要で、光ファイバでは通信距離や鍵生成速度に制約がある</li>
    <li>実機の検出器等を狙う実装攻撃(サイドチャネル)が課題</li>
    <li>デコイ状態法は個別のプロトコルではなく、弱いコヒーレント光を使う実システムで光子数分離攻撃(PNS攻撃)を防ぐ技術<br>(BB84等と組み合わせて用いる)</li>
    <li>数学的困難性に基づく耐量子計算機暗号(PQC)とは別系統で、両者を併用する考え方もある</li>
</ul>
