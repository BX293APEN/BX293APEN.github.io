# blenderの使い方

## 1. インストール方法

1. [Blender公式サイト](https://www.blender.org/) にアクセスする
2. トップページの「Download Blender」ボタンをクリックすると、OS（Windows / macOS / Linux）を自動判別してインストーラーが提供される
3. ダウンロードしたインストーラーを実行し、画面の指示に従ってインストールする（Windowsの場合は `.msi`、macOSの場合は `.dmg`）
4. 通常版のほか、長期サポート版（LTS）も選択可能。業務用途など安定性を重視する場合はLTS版を推奨

| 項目 | 内容 |
| --- | --- |
| 対応OS | Windows / macOS（Intel・Apple Silicon対応） / Linux |
| 価格 | 無料（オープンソース） |
| LTS版 | 長期サポート版。バグ修正中心で機能追加が少なく安定性重視の場合におすすめ |
| 通常版 | 最新機能をいち早く使えるが、安定性はLTSより劣る場合がある |

## 2. 環境設定

### 日本語設定

1. メニューバーの `Edit（編集）` → `Preferences（プリファレンス）` を開く（ショートカット：`Ctrl` `Alt` `U`）
2. 左側タブから `Interface（インターフェース）` を選択
3. 下部の `Translation（翻訳）` 項目を展開する
4. `Language（言語）` を `Japanese（日本語）` に変更する
5. `Affect（適用範囲）` で「ツールチップ」「インターフェース」「新規データ」のうち日本語化したい範囲にチェックを入れる
6. 設定は自動保存されるが、次回以降も確実に反映させたい場合は画面右上の `Save Preferences` を押す

> **メモ**：一部の専門用語だけ英語のままにしたい場合は、`Affect` のチェックを調整することで部分的な日本語化も可能。

### アドオンの追加方法

1. `Edit（編集）` → `Preferences（プリファレンス）` を開く
2. 左側タブから `Add-ons（アドオン）` を選択
3. 右上の `Install...` ボタンをクリックし、ダウンロードしたアドオンファイル（`.zip` または `.py`）を選択する
4. インストール後、一覧に追加されたアドオン名の左側にあるチェックボックスにチェックを入れて有効化する
5. 有効化したアドオンは `N` キーのサイドバーや `Shift` `A` の追加メニューなどに反映される

### おすすめのアドオン

| アドオン名 | 用途 |
| --- | --- |
| Import AutoCAD DXF Format | AutoCADで作成したDXFファイルをBlenderにインポートする。標準搭載アドオンで、`Preferences` → `Add-ons` で「DXF」と検索すると見つかる |
| STEPper（またはSTEP形式インポート用アドオン） | AutoCAD等からエクスポートしたSTEPファイルをインポートする。標準搭載ではないため別途インストールが必要 |
| 3D Print Toolbox | 3Dプリント用にモデルの厚み・穴・非多様体（non-manifold）などをチェックする。標準搭載アドオンで、`Preferences` → `Add-ons` で「3D Print」と検索すると見つかる |


### エクスポート(stl等)して3Dプリンタで印刷する方法
1. 画面右側の「シーンプロパティ」（コーンと球体のアイコン）をクリックし、「単位 (Units)」パネルを開く
2. 「単位システム (Unit System)」を「メートル法 (Metric)」にする
3. 「単位の倍率 (Unit Scale)」を `0.001` に変更する（**最重要ポイント**）
4. 「長さ (Length)」を「ミリメートル (Millimeters)」に変更する
5. エクスポートしたいオブジェクトを選択し、`File` → `Export` → `STL` を選択する
6. エクスポートダイアログの「Selection Only」にチェックを入れると、選択中のオブジェクトのみを書き出せる

> **注意**：エクスポート前に必ず `Ctrl` `A` → 「全トランスフォーム」でスケールを`1.0`に初期化しておくこと。スケールが崩れたままエクスポートすると、スライサー上で寸法が実寸と異なってしまう。

### ショートカットキーの詳細説明

#### **モード変更 (`オブジェクト選択` `Tab`)**

`Tab` キーで、選択中のオブジェクトの「オブジェクトモード」と「編集モード」を切り替えられる。

| モード | 説明 |
| --- | --- |
| オブジェクトモード | オブジェクト単位で移動・回転・拡大縮小を行うモード |
| 編集モード | オブジェクトの頂点・辺・面を個別に編集するモード |

#### オブジェクトモード

オブジェクトモード固有（編集モードでは意味が異なる、または存在しない）の主なショートカット。

| ショートカットキー | 説明 |
| --- | --- |
| `Ctrl` `J` | アクティブオブジェクトに他の選択オブジェクトを統合する |
| `Alt` `D` | データを共有したまま複製する（リンク複製） |
| `Ctrl` `P` | 選択オブジェクトをアクティブオブジェクトの子にする |
| `Alt` `P` | 親子関係を解除する |
| `M` | 選択オブジェクトを別のコレクションへ移動する |
| `Alt` `G` | 位置（移動）をクリアして原点に戻す |
| `Alt` `R` | 回転をクリアする |
| `Alt` `S` | 拡大縮小をクリアして `1.0` に戻す |
| `Ctrl` `C` / `Ctrl` `V` | プロパティ（位置・回転など）をコピー／貼り付けする |
| `Shift` `Ctrl` `Alt` `C` | オリジン（原点）を設定する |

右クリックのコンテキストメニューや「オブジェクト」メニューにあり、単独のキー一つでは実行できない代表的な項目。

| 項目 | 説明 |
| --- | --- |
| シェード：スムーズ | 面の陰影をなめらかに表示する |
| シェード：フラット | 面の陰影を面ごとにはっきり表示する |
| オリジンを設定 | オブジェクトの原点位置（重心・3Dカーソル位置など）を変更する |
| モディファイアを追加 | サブディビジョンサーフェスやブーリアンなどのモディファイアを追加する |
| コンストレイントを追加 | 他オブジェクトに追従させるなどの拘束を追加する |
| 変換をクリア | 位置・回転・スケールを個別にリセットする（`Alt` `G`/`R`/`S` と同等） |
| 変換の適用 | `Ctrl` `A` の「適用 リスト」と同じ操作（下記参照） |

> **メモ**：ここでは代表的なものに絞っている。網羅的な一覧は公式マニュアルの [Object Menu](https://docs.blender.org/manual/en/latest/scene_layout/object/editing/introduction.html) を参照。

| ショートカットキー | 説明 |

| `Ctrl` `B` | ベベル（辺・頂点を面取りする） |
| `K` | ナイフツール（自由な位置で面を切断） |
| `J` | 2点の頂点を辺で接続する |
| `M` | マージ（結合）メニューを開く |
| `P` | 選択部分を別オブジェクトとして分離する |
| `L` | マウス下の連結した面・要素を選択する |
| `Ctrl` `L` | アクティブ要素に連結するすべての要素を選択する |
| `I` | インセット（面を内側に縮小複製） |
| `Ctrl` `F` | 面（Face）メニューを開く |
| `Ctrl` `E` | 辺（Edge）メニューを開く |
| `Ctrl` `V` | 頂点（Vertex）メニューを開く |
| `U` | UV展開メニューを開く |
| `Shift` `N` | 法線を再計算する |
| `Ctrl` `T` | 選択面を三角形化する |

| 項目 | 説明 |
| --- | --- |
| クリーンアップ：非多様体を修復 | 3Dプリントなどで問題になる非多様体（ノンマニフォールド）形状を自動修復する |

### 追加 リスト (`Shift` `A`)

`Shift` `A` を押すと、現在のモードに応じた追加メニューが表示される。

#### オブジェクトモード

| リスト項目 | 説明 |
| --- | --- |
| メッシュ | 立方体・UV球・ICO球・円柱・円錐・トーラス・平面・グリッド・サル（Suzanne）などの多角形ポリゴン形状を追加する |
| カーブ | ベジェ曲線・円・パスなど、制御点で滑らかな形状を作れるオブジェクトを追加する |
| サーフェス | NURBSサーフェスなど、曲面をパラメトリックに編集できるオブジェクトを追加する |
| メタボール | 互いに融合するような有機的な形状を作れるオブジェクトを追加する |
| テキスト | 3D文字（フォントオブジェクト）を追加する |
| グリースペンシル | 2D／3D描画用のストロークオブジェクトを追加する |
| ボリューム | OpenVDBなどのボリュームデータを読み込むオブジェクトを追加する |
| アーマチュア | キャラクターなどを動かすための骨（ボーン）構造を追加する |
| ラティス | 他オブジェクトを緩やかに変形させるための格子オブジェクトを追加する |
| エンプティ | 見た目を持たない、目印や親子関係の基準点として使うオブジェクトを追加する |
| 画像 | 参照用の画像や背景画像を追加する |
| ライト | ポイント・サン・スポット・エリアなどの光源を追加する |
| ライトプローブ | 反射やGI（間接照明）計算用のプローブを追加する |
| カメラ | レンダリング用の視点となるカメラを追加する |
| フォースフィールド | 物理演算（パーティクルや布など）に影響を与える力場を追加する |
| コレクションインスタンス | 既存のコレクションを複製せずに参照表示するインスタンスを追加する |

> **メモ**：網羅的な一覧は公式マニュアルの [Add Menu](https://docs.blender.org/manual/en/latest/scene_layout/object/introduction.html) を参照。表示される項目は有効化しているアドオンによって増える場合がある。


#### 編集モード

編集モードで `Shift` `A` を押した場合、オブジェクトモードのような全種類のオブジェクト一覧ではなく、編集中のオブジェクトの種類に応じたプリミティブのみが表示される（頂点・辺・面や押し出しは「追加」メニューの項目ではなく、それぞれ独立したショートカット `Ctrl` `V` / `Ctrl` `E` / `Ctrl` `F` / `E` から実行する編集操作である）。

| リスト項目 | 説明 |
| --- | --- |
| メッシュ編集中 | オブジェクトモードの「メッシュ」と同じ、立方体・UV球・円柱などのプリミティブを現在のメッシュ内に追加する |
| カーブ編集中 | 編集中のカーブと同じ種類の制御点セット（ベジェ曲線・円など）を追加する |
| サーフェス編集中 | 編集中のサーフェスと同じ種類のNURBS要素を追加する |

> **メモ**：オブジェクトの種類（メッシュ／カーブ／サーフェスなど）によって編集モードが持つ「追加」メニューの内容が変わる。また、アーマチュアなど一部のオブジェクトタイプは編集モードに専用の「追加」メニュー項目を持たない。


### 適用 リスト (`Ctrl` `A`)

| 項目 | 説明 |
| --- | --- |
| 位置 | オブジェクトの位置（座標）をリセットし、原点に適用する |
| 回転 | オブジェクトの回転値をリセットし、形状に適用する |
| スケール | オブジェクトの拡大縮小値をリセットし、形状に適用する |
| 全トランスフォーム | 位置・回転・スケールをまとめて適用する。**寸法を数値入力で変更した後は必ずこれを実行し、スケールを `1.0` に初期化すること**（忘れるとスライサー出力時にサイズが狂う原因になる） |
| 回転とスケール | 回転とスケールのみをまとめて適用する（位置はそのまま） |
| ビジュアルトランスフォームを適用 | コンストレイントなどで見た目上変形している状態を、実際のトランスフォーム値として確定する |
| デルタ位置を適用 | デルタトランスフォーム（アニメーション用に元の値へ上乗せする位置）を通常の位置に統合する |
| デルタ回転を適用 | デルタトランスフォームの回転を通常の回転に統合する |
| デルタスケールを適用 | デルタトランスフォームのスケールを通常のスケールに統合する |
| 全デルタトランスフォーム | デルタ位置・回転・スケールをまとめて通常のトランスフォームに統合する |

> **メモ**：`Ctrl` `A` の適用リストはオブジェクトモードのみで使用する（編集モードには存在しない）。網羅的な一覧は公式マニュアルの [Apply](https://docs.blender.org/manual/en/latest/scene_layout/object/editing/apply.html) を参照。

### ショートカットキーだけでは完結しない主な操作

「ショートカットキーについて」に挙げた項目のうち、キーを押すだけで操作が完了せず、続けてマウス操作や数値入力・確定操作が必要なものをまとめる。

| 項目 | 完結までの流れ |
| --- | --- |
| `G`（移動） | キーを押した後、マウス移動またはテンキーで数値入力し、`左クリック` か `Enter` で確定、`右クリック` か `Esc` でキャンセル |
| `R`（回転） | `G` と同様にマウス操作か数値入力の後、`左クリック`／`Enter` で確定 |
| `S`（拡大縮小） | `G` と同様にマウス操作か数値入力の後、`左クリック`／`Enter` で確定 |
| `E`（押し出し） | 押し出す方向へマウスを動かすか数値入力し、`左クリック`／`Enter` で確定 |
| `Shift` `A`（追加） | メニューから項目を選択するまで操作は完了しない |
| `Ctrl` `A`（適用） | メニューから適用したい項目を選択するまで操作は完了しない |
| `Ctrl` `S`（保存） | 未保存（新規）ファイルの場合は保存先ダイアログが開くため、パスを指定して「Save」を押すまで完了しない |

## 操作例

> **メモ**：以下の操作手順は内容を確認済み。Blenderのバージョンによってメニュー名や配置が多少異なる場合がある。


### オブジェクトのサイズを変更する

例：19mm × 39mm の直方体を作る場合

1. `Shift` `A` → 「メッシュ (Mesh)」 → 「立方体 (Cube)」を追加
2. `N` キーでサイドバー（トランスフォーム情報）を表示
3. 「寸法 (Dimensions)」に数値を直接入力する（例：X: `19mm` / Y: `39mm` / Z: 任意の厚み 例 `10mm`）
4. オブジェクトを選択した状態で `Ctrl` `A` → 「全トランスフォーム (All Transforms)」を実行し、スケールを `1.0` に初期化する（**忘れるとスライサーでサイズが狂う原因になる**）

既存オブジェクトのサイズを変更する場合は、以下の2つの方法がある。

| 方法 | 手順 | 特徴 |
| --- | --- | --- |
| Nパネルで寸法を直接入力 | サイドバーの「寸法」欄に数値を直接入力する | 正確な数値指定がしやすいが、変更後は必ず「全トランスフォーム」の適用が必要 |
| `S` キーでスケール変更 | オブジェクトを選択し `S` キー→数値またはマウス操作で拡大縮小する | 感覚的に操作できるが、こちらもスケール値が`1.0`からずれるため後で適用が必要 |



### ブーリアンモディファイアで穴を開ける（くり抜き）

例：土台に「10mm × 39mm × 1mm」の四角い穴をくり抜く場合

1. **カッター用オブジェクトを作成する**
   `Shift` `A` → 「メッシュ」 → 「立方体」を追加し、サイドバーの「寸法」を X: `10mm` / Y: `39mm` / Z: `1mm` に設定する
   `Ctrl` `A` → 「全トランスフォーム」を実行する
2. **位置を合わせる**
   カッター用の立方体を、くり抜きたい場所に移動させる
3. **ブーリアンモディファイアを設定する**
   - くり抜かれる側の本体オブジェクトを選択する
   - モディファイアプロパティ（スパナのアイコン）→「モディファイアを追加」→「生成」→「ブーリアン (Boolean)」を選択する
   - 演算方法を「差分 (Difference)」にする
   - 「オブジェクト」欄のスポイトアイコンで、先ほど作ったカッター用の立方体を指定する
4. **確定する**
   問題なければブーリアンモディファイアの「適用 (Apply)」を押して確定する
5. **後片付け**
   カッターとして使った立方体は不要になるため、選択して `X` キーで削除する

| 演算方法 | 説明 |
| --- | --- |
| 差分 (Difference) | 本体からカッターオブジェクトの形状をくり抜く（穴あけに使用） |
| 統合 (Union) | 本体とカッターオブジェクトの形状を結合する |
| 交差 (Intersect) | 本体とカッターオブジェクトが重なる部分だけを残す |

### オブジェクトの原点（回転・拡大縮小の基準点）を移動する

例：直方体の原点を端の角に移動して、そこを基準に回転・スケールしたい場合

1. `Shift` + 右クリック で原点にしたい位置（端の角の頂点など）に3Dカーソルを移動する（編集モードで頂点を選択し `Shift` `S` →「カーソル→選択物」でも可）
2. オブジェクトモードに戻り、原点を移動したいオブジェクトを選択する
3. 右クリックメニュー（または「オブジェクト」メニュー）→「原点を設定」→「原点を3Dカーソルへ」を選択する
4. オブジェクトの原点マーカー（オレンジの点）が指定した位置に移動し、以後 `R`（回転）・`S`（拡大縮小）はこの点を基準に行われる

| 原点の設定方法 | 説明 |
| --- | --- |
| 原点を3Dカーソルへ | 3Dカーソルの位置に原点を移動する（角や端を基準にしたい場合に使用） |
| 原点をジオメトリへ | オブジェクトの形状の重心（バウンディングボックス中心）に原点を戻す |
| 3Dカーソルを原点へ | 逆に、3Dカーソルの方をオブジェクトの原点位置へ移動する |
