tracerouteコマンド使い方

**ターミナル** ```bash traceroute [オプション] [宛先IPアドレス/ホスト名] [パケット長] ```

※ パケット長
送信パケット長(バイト)を指定
デフォルト : `60` (IPv4) / `80` (IPv6)
