データベースサーバ

データベースの分類

分類 種類 特徴 サブ分類 説明 具体例
DB RDBMS
  • 表(テーブル)形式でデータを管理
  • スキーマを事前に定義
  • ACID特性によるトランザクション保証
  • SQLによる問い合わせ・結合が可能
 (リレーショナル型)
  • 行と列からなる表でデータを表現
  • 外部キーによりテーブル同士を関連付け
  • 整合性・正確性が求められる業務系システムに適する
  • MySQL
  • PostgreSQL
  • SQLite
  • Oracle Database
  • SQL Server
NoSQL
  • スキーマレス(柔軟なデータ構造)
  • 水平分散によるスケールアウトが容易
  • 大量データ・高速アクセスに強い
  • 結合(JOIN)には不向き
 KVS型
  • キーと値のペアでデータを保持
  • 構造がシンプルで読み書きが非常に高速
  • キャッシュやセッション管理に多用
  • Redis
  • Memcached
  • Amazon DynamoDB
ドキュメント型
  • JSON/BSON等の半構造化ドキュメント単位で保存
  • ドキュメントごとに異なる構造を持てる
  • アプリケーションのオブジェクトと親和性が高い
  • MongoDB
  • Couchbase
  • Amazon DocumentDB
カラムファミリ型
  • 行ごとに異なるカラムを持てる列指向のデータ構造
  • 大規模・書き込み中心のワークロードに強い
  • ノード追加による水平スケールが得意
  • Apache Cassandra
  • HBase
  • ScyllaDB
グラフ型
  • ノードとエッジでデータ間の関係を表現
  • 関係性をたどる探索クエリが高速
  • SNSの人間関係やレコメンドに適する
  • Neo4j
  • Amazon Neptune
  • ArangoDB
