サーバの構築

Nginx Docker(Flask) に CDNを使用する

リポジトリのダウンロード

ターミナル 
git clone https://github.com/BX293APEN/Nginx-Flask-CDN-Docker.git
cd Nginx-Flask-CDN-Docker

オリジンサーバの起動

ターミナル 
cd Nginx-Flask-Docker
docker compose up --build -d
cd ../

エッジサーバ(キャッシュサーバ)の起動

ターミナル 
cd Nginx-Flask-CDN-Docker
docker compose up --build -d

CDNの仕組み

データ取得方法

| 構成要素 | 役割 | 主な技術・設定 | |---|---|---| | DNS | ユーザーを最寄りのエッジへ誘導 | `CNAME`, GeoDNS, Anycast | | エッジサーバ | キャッシュからコンテンツを直接配信 | TTL, `Cache-Control`, TLS終端 | | オリジンシールド | エッジからオリジンへの問い合わせを集約 | 中間キャッシュ層 | | オリジン | 元コンテンツの保持と配信 | Webサーバ, ストレージ, LB |

| 項目 | キャッシュヒット | キャッシュミス | |---|---|---| | 応答元 | エッジサーバ | オリジン(経由) | | レイテンシ | 低い | 高い | | オリジン負荷 | なし | あり | | `X-Cache` ヘッダ | `HIT` | `MISS` |
