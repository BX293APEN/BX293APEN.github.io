dnsmasqによるDHCPサーバの構築

※ dhcpdは開発が終わったため、dnsmasqで設定

dnsmasqのインストール

ターミナル 
sudo apt install dnsmasq

設定ファイル

ターミナル 
sudo nano /etc/dnsmasq.d/lan.conf

エディタ 
# /etc/dnsmasq.d/lan.conf

# ※設定項目のスペースを勝手に空けると構文チェックに通らなくなる

# =================================================================
# 共通・インターフェース設定
# =================================================================
interface=eth0          # 待ち受けインターフェース
interface=lo            # 待ち受けインターフェース
domain-needed           # ドット無しの名前を上流DNSへ転送しない
bogus-priv              # プライベートIPの逆引きを上流へ転送しない
local=/lan/             # ローカル専用ドメイン
local=/local.lan/       # ローカル専用ドメイン
domain=lan

# =================================================================
# DNSサーバー設定
# =================================================================

# port=0                # DNS 機能の無効化
no-resolv               # サーバー本体の /etc/resolv.conf (上流DNS設定)を無視
server=1.1.1.1          # 上流DNS
server=8.8.8.8          # 上流DNS

# =================================================================
# 独自ゾーン設定
# =================================================================
no-hosts                # /etc/hosts を 読み込まない (名前解決はhost-recordのみ)
host-record=gateway.lan,gateway,192.168.10.1
host-record=raspi5.lan,raspi5,192.168.10.64
host-record=raspi5.local.lan,192.168.10.64

# =================================================================
# DHCPサーバー設定
# =================================================================

# DHCP範囲 : 192.168.10.100/24 - 192.168.10.200/24
# リース期間 : 24時間
dhcp-range=192.168.10.100,192.168.10.200,255.255.255.0,24h


dhcp-option=option:router,192.168.10.1          # デフォルトゲートウェイ
dhcp-option=option:dns-server,192.168.10.64     # DNSサーバ
# dhcp-option=option:ntp-server,192.168.10.99   # NTPサーバ
# dnsmasq --help dhcpでオプション名確認

設定の適用

ターミナル 
dnsmasq --test                      # 構文チェック
sudo systemctl restart dnsmasq      # 設定の適用
sudo journalctl -u dnsmasq -n 20    # 動作ログチェック
