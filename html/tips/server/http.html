サーバの構築

サーバの構築手順

Nginx (CGI)

必要なパッケージのインストール

##### ※注意 - Python 3.12 以降では `cgi` `cgitb` モジュールが削除されています **古い** CGIスクリプトは動作しないため、 **環境変数** と **stdin** を使ったフォーム処理に書き換える必要があります。 → **代替モジュール** [`libcgipy`](https://pypi.org/project/libcgipy/) を作成しました

ターミナル 
sudo apt install nginx fcgiwrap
pip install libcgipy    # Pythonスクリプトを動かす場合

設定ファイルの編集

ターミナル 
sudo nano /etc/nginx/sites-available/[Project Name]

エディタ 
server {
    listen 80;
    server_name radicon.lan;

    location /cgi-bin/ {
        gzip off;
        alias [path]/cgi-bin/;
        fastcgi_pass unix:/run/fcgiwrap.socket;
        include /etc/nginx/fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $request_filename;
        fastcgi_param PATH_INFO $fastcgi_path_info;
    }
}

設定の変更

ターミナル 
sudo ln -s /etc/nginx/sites-available/[Project Name] /etc/nginx/sites-enabled/
sudo rm /etc/nginx/sites-enabled/default
sudo nginx -t # テスト

cd [Project Name]

バッチファイル (.bat) 
@echo off

if "%1" == "" (
    goto help

) else if "%~1" == "/?" (
    goto help

) else if "%~1" == "-help" (
    goto help

) else if "%~1" == "-app" (
    if "%2" == "" (
        echo アプリ作成
        set /p appName="アプリ名 : "
    ) else (
        set appName=%2
    )
    setlocal enabledelayedexpansion
    python manage.py startapp !appName!
    echo 完了しました
    pause > nul
    exit /b

) else if "%~1" == "-mig" (
    if "%2" == "" (
        echo マイグレーション
        set /p appName="アプリ名 : "
    ) else (
        set appName=%2
    )
    setlocal enabledelayedexpansion
    python manage.py makemigrations !appName!
    python manage.py migrate
    echo 完了しました
    pause > nul
    exit /b

) else if "%~1" == "-run" (
    python manage.py runserver
    pause>nul
    exit /b

) else if "%~1" == "-col" (
    python manage.py collectstatic
    pause>nul
    exit /b

) else if "%~1" == "--create-admin" (
    python manage.py createsuperuser
    pause>nul
    exit /b

) else (
    echo 引数が違います
    goto help
)

:help
    echo %~0
    echo [/?]             : help
    echo [-app] [appName] : 指定したアプリを作成
    echo [-mig] [appName] : 指定したアプリのマイグレーションを実行
    echo [-run]           : ローカルサーバ立ち上げ
    echo [-col]           : staticファイルを集める
    echo [--create-admin] : 管理者登録
    cmd
    exit /b

HTTPヘッダ 

フィールド名 : 属性=値; 値;
要素意味
 
フィールド名
ヘッダ名 (: の左側)
属性=値
値を持つ属性 (例: max-age=3600)
値
属性を持たないヘッダ本体の値、または値なしの属性 (フラグ)
;
属性・値の区切り (ヘッダにより , 区切り)
フィールド名種別説明属性説明値説明
 
Content-Type
共通ボディのメディアタイプ-
[type]/[subtype]
例: text/html / application/xml
-
application/x-www-form-urlencoded
XHR/Fetch: フォーム形式の送信
-
application/json
XHR/Fetch: JSONの送受信 (クロスオリジンではプリフライト対象)
-
multipart/form-data
XHR/Fetch: ファイル送信 (FormData 使用時はブラウザが自動付与)
charset
文字エンコーディング
UTF-8
テキスト系で指定
boundary
multipartの区切り文字列
[文字列]
multipart/form-data 時に必須
 
Content-Length
共通ボディのサイズ-
[バイト数]
Transfer-Encoding 使用時は付与しない
Content-Encoding
共通ボディに適用された圧縮形式-
gzip / deflate / br
Accept-Encoding の中から選択される
Transfer-Encoding
共通ボディの転送方式-
chunked
サイズ不明のデータを分割送信 (HTTP/2以降は不使用)
Connection
共通ネットワーク接続状態の制御-
keep-alive / close / Upgrade
接続の維持 / 切断 / プロトコル切替 (HTTP/2以降は不使用)
Date
共通メッセージ生成日時-
[ddd, dd MMM yyyy HH:mm:ss GMT]
常にGMT
 
Cache-Control
共通キャッシュの扱い方
(コンマ区切りで複数指定)
no-cache
使用前に毎回サーバへ検証-
no-store
キャッシュ禁止 (保存しない)-
public / private
共有キャッシュ可 / ブラウザのみ可-
max-age
有効期間
[秒数]
例: max-age=3600
s-maxage
共有キャッシュ向けの有効期間
[秒数]
-
must-revalidate
期限切れなら必ず確認-
immutable
有効期間中は更新されない (再検証不要)-
no-transform
中継が内容を変換することを禁止-

0.0 ～ 1.0

リクエスト対応している圧縮形式-
gzip, deflate, br, zstd
