送信サーバ (Postfix)

必要なパッケージのインストール

##### **General mail configuration type** (main_mailer_type) | タイプ | 内容 | |---|---| | No configuration | 設定を一切行わない。`main.cf` などを手動で作成する場合に選ぶ | | Internet Site | SMTP で直接メールを送受信する。インターネット上のサーバと直接やり取りする一般的な構成 | | Internet with smarthost | 受信は直接 SMTP で行い、送信は外部のリレーサーバ (smarthost) 経由にする。ISP の SMTP サーバなどを経由する場合に使う | | Satellite system | 送受信ともにすべて外部の smarthost に任せる。ローカルには配送しない端末向け | | **Local only** | 同一マシン内のユーザ間のみメールを配送する。外部との送受信は行わない |
ターミナル 
echo "postfix postfix/main_mailer_type select Local only" | sudo debconf-set-selections
echo "postfix postfix/mailname string [ドメイン名]" | sudo debconf-set-selections
sudo DEBIAN_FRONTEND=noninteractive apt install postfix -y

設定

ターミナル 
# 変数の設定
DOMAIN="[ドメイン名]"
INIF="loopback-only"                        # 待受IPアドレス/ホスト名 (loopback-only / all / 127.0.0.1 ...)
MAILRELAY="127.0.0.0/8"                     # リレーを許可するネットワーク (127.0.0.0/8 ...)

MAIL_ROOT=""                                # デフォルト値 : /Programs/Maildir/
# MAIL_ROOT="[メールの保存先フォルダ]"        # 任意のフォルダに保存する場合は、この行を有効にする

: "${MAIL_ROOT:=/Programs/Maildir/}"
HOST_SHORT=$(hostname -s)

# 基本設定
# ' : $の展開防止
# default_transport / relay_transport : error → 外部への送信を拒否 : Local Only
# inet_interfaces
#   all : 全インターフェースで待ち受け
#   loopback-only : 自分のみ待ち受け
sudo postconf -e \
    "myhostname                     = $HOST_SHORT.$DOMAIN" \
    "mydomain                       = $DOMAIN" \
    'mydestination                  = $myhostname, localhost.$mydomain, localhost, $mydomain' \
    "mynetworks                     = ${MAILRELAY}" \
    "inet_interfaces                = ${INIF}" \
    "inet_protocols                 = ipv4" \
    "default_transport              = error" \
    "relay_transport                = error" \
    "smtpd_recipient_restrictions   = permit_mynetworks,reject_unauth_destination"

# メールの保存先

sudo mkdir -p "$MAIL_ROOT"
sudo chown root:mail "$MAIL_ROOT"
sudo chmod 1777 "$MAIL_ROOT"
sudo postconf -e "home_mailbox =" "mail_spool_directory = $MAIL_ROOT/"

sudo chmod 777 /var/mail    # 注意 : 775 に変更推奨


# 反映
sudo postfix check
sudo newaliases

必要なパッケージのインストール

ターミナル 
sudo apt install dovecot-core dovecot-imapd dovecot-pop3d -y

設定

ターミナル 
# 設定フォルダ
cd /etc/dovecot

# 変数の設定
LISTENIF="127.0.0.1, ::1"                         # 待受アドレス (閉じた環境以外では 127.0.0.1 推奨)
# MAIL_ROOT="[送信サーバと同じ値にする]"            # メールの保存先フォルダ

: "${MAIL_ROOT:=/Programs/Maildir/}"
LOC="$MAIL_ROOT/%{user}";


if grep -q "^listen *=" dovecot.conf; then                                  \
    sudo sed -i "s|^listen *=.*|listen = ${LISTENIF}|" dovecot.conf;        \
else                                                                        \
    echo "listen = ${LISTENIF}" | sudo tee -a dovecot.conf;                 \
fi

# メールの保存先
if grep -q "^mail_home *=" conf.d/10-mail.conf; then                                    \
    sudo sed -i "s|^mail_home *=.*|mail_home = $LOC|" conf.d/10-mail.conf;              \
else                                                                                    \
    echo "mail_home = $LOC" | sudo tee -a conf.d/10-mail.conf;                          \
fi

if grep -q "^mail_driver *=" conf.d/10-mail.conf; then                                  \
    sudo sed -i "s|^mail_driver *=.*|mail_driver = maildir|" conf.d/10-mail.conf;       \
else                                                                                    \
    echo "mail_driver = maildir" | sudo tee -a conf.d/10-mail.conf;                     \
fi

if grep -q "^mail_path *=" conf.d/10-mail.conf; then                                    \
    sudo sed -i "s|^mail_path *=.*|mail_path = $LOC|" conf.d/10-mail.conf;              \
else                                                                                    \
    echo "mail_path = $LOC" | sudo tee -a conf.d/10-mail.conf;                          \
fi


# 平文認証を許可 (検証環境のみ : パスワードが平文で流れる)
if grep -q "^auth_allow_cleartext *=" conf.d/10-auth.conf; then                                     \
    sudo sed -i "s|^auth_allow_cleartext *=.*|auth_allow_cleartext = yes|" conf.d/10-auth.conf;     \
else                                                                                                \
    echo "auth_allow_cleartext = yes" | sudo tee -a conf.d/10-auth.conf;                            \
fi

# TLS を無効化 (検証環境のみ : 通信が暗号化されない)
if grep -q "^ssl *=" conf.d/10-ssl.conf; then               \
    sudo sed -i "s|^ssl *=.*|ssl = no|" conf.d/10-ssl.conf; \
else                                                        \
    echo "ssl = no" | sudo tee -a conf.d/10-ssl.conf;       \
fi

# 反映
sudo systemctl enable dovecot

sudo systemctl status dovecot --no-pager

#!/usr/bin/env python3

import base64, email, poplib, imaplib
from email.header import decode_header, make_header
# https://docs.python.jp/3/library/poplib.html

class POP3():
    def __init__(
        self, 
        account, 
        password, 
        host = "localhost", 
        port = 110
    ):
        self.popclient = poplib.POP3(host, port)
        self.popclient.user(account)
        self.popclient.pass_(password)
    
    def recv_mail(self):
        msgList = [] # 取得したMIMEメッセージを格納するリスト
        msgNum = self.popclient.stat()[0]  # POP3サーバに存在するメールの数を取得
        for i in range(msgNum):
            msgBytes = b""
            for line in self.popclient.retr(i+1)[1]:  # i+1から始まる
                msgBytes += line + b"\n"
            msgList.append(email.message_from_bytes(msgBytes))
        
        return msgList
    
    def del_mail(self, num = 0):
        self.popclient.dele(num + 1)
        
    def __enter__(self):
        return self
    
    def __exit__(self, *args):
        self.popclient.quit()

class IMAP4():
    def __init__(
        self, 
        account, 
        password, 
        host = "localhost", 
        port = 143
    ):
        self.imapclient = imaplib.IMAP4(host, port)
        self.imapclient.debug = 3  # 各命令をトレースする
        
        self.imapclient.login(account, password)
        self.sel_box()
    
    def sel_box(self, box = "INBOX"):
        self.imapclient.select(box) # メールボックスの選択
        
    def recv_mail(self):
        typ, data = self.imapclient.search(None, "ALL")  # data = [b"1 2 3 4 ..."]
        datas = data[0].split()
        fetchNum = len(datas)
        msgList = []  # 取得したMIMEメッセージを格納するリスト
        for num in datas:
            typ, data = self.imapclient.fetch(num, '(RFC822)')
            msg = email.message_from_bytes(data[0][1])
            msgList.append(msg)
            
        return msgList
    
    def del_mail(self, num = 0):
        typ, data = self.imapclient.uid('search', None, 'ALL')
        datas = data[0].split()
        self.imapclient.uid('STORE', datas[num], '+FLAGS', '\\Deleted')
    
    def __enter__(self):
        return self
    
    def __exit__(self, *args):
        self.imapclient.close()
        self.imapclient.logout()

#!/usr/bin/env python3

import os
import smtplib
from email.mime.text import MIMEText

class SendMail():
    def __init__(
        self, 
        account = None, 
        password = None, 
        server = "smtp.gmail.com", 
        port = 25
    ):
        self.smtpobj = smtplib.SMTP(server, port)   # SMTPオブジェクト作成
        self.smtpobj.ehlo()                         # SMTPサーバとの接続を確立
        
        if self.smtpobj.has_extn('STARTTLS'):
            self.smtpobj.starttls()
            self.smtpobj.ehlo()
        
        if account is not None:
            self.smtpobj.login(account, password)       # SMTPサーバーへログイン
        
    def __enter__(self):
        return self
    
    def send_mail(
        self, 
        mail_from, 
        mail_to, 
        mail_subject, 
        mail_body
    ):
        """ メッセージのオブジェクト """
        msg = MIMEText(mail_body, "plain", "utf-8")
        msg['Subject'] = mail_subject
        msg['From'] = mail_from
        msg['To'] = mail_to
        
        try:
            self.smtpobj.sendmail(mail_from, mail_to, msg.as_string())
            return "メール送信完了"
        
        except:
            return "失敗"
    
    def __exit__(self, *args):
        self.smtpobj.quit()
        
        
if __name__== "__main__": # 直接起動の場合はこちらの関数を実行
    with SendMail(
        #account     = "[自分のアカウント名]",
        #password    = "[自分のパスワード]",
        server      = '[SMTPサーバのホスト名]',
        port        = [SMTPサーバのポート番号 デフォルト : 25]
    ) as email:
        
        """ メール設定 """

        mail_to         = "[送信先のアカウント名]@localhost"               # 送信先アドレス(To)

迷惑メール対策

対策 正式名称 仕組み 利用状況 概要
SMTP-AUTH SMTP Service Extension for Authentication
  1. クライアントがSMTPセッション内でID/パスワードを送る
  2. サーバがユーザーを認証する
  3. 認証に成功したセッションのみ送信(中継)を許可する
 〇
  • 送信サーバ側の送信認証
  • 認証済みユーザー以外の送信を拒否する
  • 標準ポートは587(サブミッション)・465(SMTPS)
  • 許可はセッション単位
  • 認証情報の漏洩対策としてTLSが必須
  • OP25Bとの相性が良い(587番を使用)
POP before SMTP ポップ ビフォア エスエムティーピー
  1. クライアントがPOP3認証を行う
  2. 認証に成功したクライアントのIPアドレスを許可対象とする
  3. そのIPアドレスからのSMTP送信を一定時間許可する
 ✖
  • 送信認証
  • 認証対象はクライアントのIPアドレス
  • 標準ポートは25のため、OP25Bとの相性が悪い
  • 許可の持続は数分〜数十分
  • NAT配下の共有IPでは他者にも許可が及ぶ
OP25B Outbound Port 25 Blocking
  1. ISPが動的IP等からの通信を監視する
  2. 外部ネットワーク宛のポート25(SMTP)通信を遮断する
 〇
  • ネットワークレベルの送信ポート制限
  • 迷惑メールの発信元となるスパム送信ボットの通信を遮断する
中継制限 オープンリレーの防止
  1. 第三者からの中継要求を判定する
  2. 許可されていない中継を拒否する
 〇
  • 分類: 送信サーバ側
  • 第三者中継を禁止する
DKIM DomainKeys Identified Mail
  1. 送信側MTAが電子署名をヘッダ(DKIM-Signature)に付与する
  2. 受信側がDNS上の公開鍵を取得する
  3. 公開鍵で署名を検証する
 〇
  • 送信ドメイン認証 / 送信元の検証
  • 送信元ドメインの正当性を確認できる
  • ヘッダ・本文の改ざんを検知できる
DMARC Domain-based Message Authentication, Reporting, and Conformance
  1. SPF/DKIMの認証結果を取得する
  2. Fromドメインとの整合性(アライメント)を評価する
  3. 失敗時は送信ドメイン側が指定したポリシーに従って処理する
  4. 集計レポートを送信ドメイン側へ送る
 〇
  • 送信ドメイン認証 / 送信元の検証
  • 失敗時の扱い(ポリシー)と集計レポートを送信ドメイン側が指定できる
  • DMARCポリシー(p=タグ)
    値 動作 用途
    none 認証失敗でも何もしない(レポートのみ受け取る) 導入初期の監視
    quarantine 認証失敗メールを隔離する(迷惑メールフォルダ等) 段階的な強化
    reject 認証失敗メールを受信拒否する 本格運用
ベイジアンフィルタリング Bayesian Filtering
  1. 迷惑メール・通常メールから単語の出現頻度を学習する
  2. 受信メールの単語の出現頻度を調べる
  3. 迷惑メールらしさを確率で算出して判定する
 〇
  • 分類: 内容ベースの判定 / 受信側フィルタ
  • ベイズ理論(ナイーブベイズ)を利用する(最終行は、∩と余事象のバーだけで書き換えた式) \[ \begin{aligned} P(A \mid B) &= \frac{P(B \mid A)\,P(A)}{P(B)} \\ &= \frac{P(A \cap B)}{P(B)} \\ &= \frac{P(A \cap B)}{P(A \cap B) + P(\bar{A} \cap B)} \end{aligned} \]
    変形 根拠
    1行目 → 2行目 乗法定理 \(P(B \mid A)\,P(A) = P(A \cap B)\)
    2行目 → 3行目 全確率の定理 \(P(B) = P(A \cap B) + P(\bar{A} \cap B)\)
    記号 意味
    \(A\) メールが迷惑メールである事象
    \(\bar{A}\) \(A\) の余事象(メールが正常である事象)
    \(B\) メールに特定の単語が含まれる事象
    \(P(A \mid B)\) その単語を含むメールが迷惑メールである確率
  • 学習により精度が向上する
  • 誤判定に注意が必要(学習データの偏り・不足や、しきい値の設定で発生する)
    種類 別名 内容
    フォールスポジティブ 誤検知・過検知 正常なメールを迷惑メールと誤判定する(重要なメールを見落とす恐れがある)
    フォールスネガティブ 検知漏れ 迷惑メールを正常なメールと誤判定し、受信箱に届いてしまう
